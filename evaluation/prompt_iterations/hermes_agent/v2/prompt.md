# v2 프롬프트

## 비교 정의

사실성 검토, 불확실성 표시, 구조 설계, HTML 생성과 자체 검수를 명시한 개선 방식이다.

## 사용 프롬프트

`../../../../prompts/comparison/prompt_ai_news_content_package_common_v6_final.md`

## 처리 흐름

```text
기사 입력
→ 핵심 사실과 원문 주장 구분
→ 불확실성 및 최신 확인 필요 항목 표시
→ 콘텐츠 구조 설계
→ 마크다운과 HTML 분리 생성
→ 이미지·영상·본문 메시지 일치 확인
→ HTML·필수 섹션 자체 검수
→ 최종 결과 출력
```

## 추가된 통제

- 사실 확인 필요 항목
- 자동 파싱 구분자
- 이미지 3개와 본문 위치 연계
- Sora 필수 문구
- 완결형 HTML 및 인라인 CSS
- 출력 전 10개 항목 자체 검수
