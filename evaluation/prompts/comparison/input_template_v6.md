# INPUT TEMPLATE — AI 뉴스 기사

아래 블록을 복사해 USER PROMPT 뒤에 붙여넣는다.

```text
[기사 정보]
기사 제목:
기사 본문:
원문 URL:
출처명:
작성일 또는 확인일:

[작성 조건]
타겟 독자:
콘텐츠 목적:
희망 문체:
게시 플랫폼:

[사실 검증]
공식 확인된 사실:
기사에서 주장하지만 추가 확인이 필요한 내용:
사용하면 안 되는 미확인 수치 또는 표현:

[출력 요청]
1. 핵심 주제
2. 제목 후보 3개와 최종 추천 제목
3. 썸네일 문구 3개
4. 한 줄 요약과 SEO 메타 설명
5. Sora 2 영상 프롬프트, 내레이션, 자막
6. 대표 이미지 프롬프트 3개와 alt 텍스트
7. 해시태그 10개 이상
8. 마크다운 패키지
9. 게시 가능한 HTML
10. 확인이 필요한 사실 목록
```

## 최소 입력 조건

- 기사 본문 또는 내용을 확인할 수 있는 원문 URL
- 출처명
- 타겟 독자
- 게시 플랫폼

최소 입력 조건이 충족되지 않으면 SYSTEM PROMPT의 `INPUT_REQUIRED` 형식으로
되묻는다.
