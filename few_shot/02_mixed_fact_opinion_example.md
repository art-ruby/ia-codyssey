# Few-shot 2 — 사실과 해석이 섞인 기사

## 예시 유형

사실, 개인 평가, 과장된 해석과 검증 필요 수치가 섞인 기사

## 목적

모델이 기사 속 주장을 그대로 확정 사실로 쓰지 않고 확인된 사실, 원문 주장, 해석 가능한 의미와 확인 필요 항목으로 구분하는지 검증한다.

## 사용자 입력 예시

```text
[뉴스기사]

Hermes Agent는 Nous Research가 만든 오픈소스 AI 에이전트 프레임워크로 소개되고 있다. 이 도구는 대화할수록 기억을 축적하고 반복 작업을 자동으로 스킬화한다고 설명한다.

Nick Spisak의 X 아티클에 따르면 한 핀테크 창업자는 역할별 AI 에이전트 5개를 운영했지만 48시간 만에 실패했다. 원문은 에이전트 간 컨텍스트 공유 실패를 원인으로 설명한다.

Hermes Agent 하나로 통합하자 모든 문제가 해결됐으며, 이는 여러 에이전트보다 하나의 에이전트가 항상 우월하다는 것을 증명한다.

Hermes는 OpenClaw보다 무조건 빠르고 가볍다. OpenClaw는 정적이고 Hermes는 스스로 계속 진화한다. Hermes는 hermes claw migrate 명령으로 OpenClaw의 모든 설정과 API 키를 자동 이전한다.

Hermes는 MIT 라이선스이며 GitHub 스타 72,000개를 기록했다. $5 VPS만 있으면 추가 비용 없이 완전 자동화 시스템을 운영할 수 있다. 로컬 모델로는 Gemma 4 26B A4B가 가장 좋다.
```

## 기대 출력 예시

```text
[사실 확인 필요 항목]
- “하나의 에이전트가 항상 우월하다”는 개인 사례를 일반화한 표현이므로 확정할 수 없다.
- 2026-07-06 공식 저장소 화면의 스타 수는 약 210k로, 기사 속 72,000개와 차이가 있다.
- hermes claw migrate는 존재하지만 API 키 이전에는 별도 옵션이 필요하고 일부 설정은 수동 검토 대상이다.
- “Gemma 4 26B A4B”는 Google 공식 문서에서 확인되지 않는다.
- $5 VPS 언급은 실행 가능성에 관한 안내이며 LLM API 비용까지 포함한 보장은 아니다.
```

## 기대 동작

- Nick Spisak 사례를 개인 사례로 귀속
- Hermes가 항상 우월하다는 결론을 제거
- MIT 라이선스와 마이그레이션 명령은 확인된 사실로 처리
- 스타 수는 확인 날짜를 붙여 최신 값과 구분
- `Gemma 4 26B A4B`는 검증 실패로 표시
- `$5 VPS`는 조건부로 표현
- 사실 요약과 의미 해설 분리

## Pass 기준

- 위험한 주장을 최소 5개 이상 식별한다.
- 확인된 사실과 미확인 주장을 구분한다.
- 과장 표현을 중립적인 문장으로 바꾼다.

## Fail 기준

- “항상 우월”, “추가 비용 없음”, “모든 설정 자동 이전”을 그대로 확정한다.
- 존재하지 않는 모델명을 공식 모델처럼 반복한다.
- 개인 사례를 전체 제품 성능으로 일반화한다.
