## 핵심 내용

- ChatGPT, Claude, Gemini로 같은 AI 뉴스 콘텐츠 생성 과제를 수행했다.
- 사실 정확성, 글 구조, HTML 완성도, 운영 편의성을 기준으로 결과를 비교했다.
- 최종 게시 결과물은 ChatGPT 결과를 기준으로 정리했다.
- 불확실한 수치와 출처가 필요한 내용은 확정 표현으로 쓰지 않는 기준을 적용했다.
