# GenAI 기초 2: 멀티모달 브랜드 광고 제작

## 1. 프로젝트 개요

- 브랜드: LAPIS
- 제품: 프리미엄 오 드 퍼퓸
- 캠페인명: The Muse of Lapis
- 광고 형식: 9:16 세로형 숏폼 브랜드 광고
- 광고 목적: 브랜드 인지도 형성
- 최종 영상: `assignments/02-genai-basic-multimodal-content/reports/LAPIS_brand_ad_final.mp4`
- 스토리보드 PDF: `assignments/02-genai-basic-multimodal-content/reports/LAPIS_storyboard_plan.pdf`

LAPIS는 사파이어 블루와 웜 골드의 시각적 정체성을 가진 프리미엄 향수 브랜드다. 이번 광고는 향이 단순한 제품을 넘어 한 사람의 분위기와 존재감을 완성한다는 메시지를 전달하는 것을 목표로 제작했다.

## 2. 브랜드 아이덴티티

- 브랜드명: LAPIS
- 제품군: 프리미엄 오 드 퍼퓸
- 캠페인명: The Muse of Lapis
- 타겟: 절제된 고급감과 조용한 존재감을 선호하는 20대 후반-30대 초반 여성
- 톤앤매너: Quiet Luxury, 미드나잇 블루, 웜 골드, 한국적 모던 헤리티지, 시네마틱 미니멀리즘
- USP: 사파이어 블루 비주얼 아이덴티티와 차분하고 지적인 존재감을 결합한 향수
- 핵심 메시지: LAPIS는 단순한 향기가 아니라, 말보다 먼저 공기 속에 남는 조용한 존재감이다.

## 3. 비주얼 및 사운드 방향

- 메인 팔레트: 미드나잇 블루, 사파이어 블루, 웜 골드, 블랙 리플렉션
- 제품 이미지: 골드 캡이 있는 사파이어 블루 LAPIS 향수병
- 인물 이미지: 절제된 스타일링과 조용한 자신감을 가진 한국 여성
- 스타일링 요소: 네이비 실크, 시어 오간자, 모던 한복에서 영감을 받은 선, 미니멀 골드 주얼리
- 공간 방향: 한옥 모티프, 격자 구조, 어두운 반사 표면, 로우키 조명
- 음성 방향: 차분하고 세련된 여성 내레이션
- 사운드 방향: 미니멀 앰비언트, 부드러운 공기감, 향수 캡 클릭, 짧은 사운드 로고

## 4. 사용 도구 및 제작 목적

- 이미지 생성: ChatGPT, 제품 및 무드 키비주얼 생성
- 영상 생성: Google Flow, 이미지 기반 모션 컷과 장면 구성
- 오디오 생성: OpenAI TTS `nova` 보이스, 한국어 내레이션 음성 생성
- 편집 도구: 캡컷(CapCut), 컷 편집, 오디오 레벨 조정, 자막/화면 카피 정리, 최종 MP4 내보내기

## 5. 제작 파이프라인

1. 브랜드 및 캠페인 콘셉트 기획
2. 브랜드 톤앤매너와 컬러 팔레트 확정
3. ChatGPT로 제품, 인물, 공간 키비주얼 생성
4. Google Flow로 이미지 기반 모션 컷 제작
5. OpenAI TTS `nova` 보이스로 내레이션 생성
6. 캡컷에서 컷 편집, 오디오 레벨 조정, 자막 및 화면 카피 정리
7. 과제 조건인 10초 이내에 맞춰 최종 MP4 내보내기

## 9. 제작 제약 관리

Google Flow는 `omni flash` 버전을 중심으로 사용했다. 실제 작업에서는 대기열이나 생성 오류가 크게 발생하지 않았지만, 크레딧 소모를 줄이기 위해 처음부터 씬 수와 생성 횟수를 제한하는 방식으로 설계했다.

- 씬 수 제한: 최종 영상 길이를 10초 이내로 맞추기 위해 5개 씬으로 구성하고, 각 씬은 약 1.9-2.0초로 고정했다.
- 생성 횟수 제한: 각 씬은 기준 이미지 1개와 영상화 결과 1개를 기본 단위로 잡고, 재생성은 장면당 최대 1회만 허용하는 방식으로 계획했다. 즉 5개 씬 기준으로 기본 5회 생성, 문제가 있는 컷만 보정해 최대 10회 이내에서 끝내는 것을 목표로 했다.
- 재생성 기준: 인물 얼굴이 바뀌는 경우, 향수병 색이 사파이어 블루에서 벗어나는 경우, 골드 캡이 사라지는 경우, 로고 텍스트가 깨지는 경우, 9:16 구도가 무너지는 경우에만 재생성했다.
- 대기열 대응: Flow 대기열이 길어질 경우 먼저 ChatGPT에서 다음 씬의 기준 이미지와 프롬프트를 준비하고, Flow 작업은 제품 컷과 엔딩 컷처럼 브랜드 인지에 중요한 장면부터 순서대로 처리하는 방식으로 설계했다.
- 대체 도구 기준: Flow 사용이 불가능하면 영상 생성은 Pika 또는 Kling으로 대체하되, 제품 형태 보존이 중요한 씬 1과 씬 5는 이미지 원본 유지 기능이 강한 도구를 우선 사용한다. 음성 생성은 OpenAI TTS가 불가능할 경우 ElevenLabs 또는 다른 TTS 도구로 대체한다.
- 편집 분리: 생성형 AI에서 모든 것을 해결하지 않고, 컷 길이 조정과 오디오 레벨 정리는 CapCut에서 처리해 불필요한 영상 재생성을 줄였다.

## 10. 에셋 표준화

톤앤매너 일관성을 위해 모든 장면의 기본 조건을 세로형 숏폼 광고에 맞춰 통일했다. 처음 생성한 캐릭터와 제품 이미지를 기준 에셋으로 삼고, Flow에서 영상화할 때 원본 이미지를 유지하도록 명시해 캐릭터와 향수병이 장면마다 달라지는 문제를 줄였다.

- 화면 비율: 최종 광고는 9:16 세로형 숏폼 기준으로 제작했다.
- 최종 해상도: 1080x1920으로 내보냈다.
- 프레임레이트: 30fps로 통일했다.
- 장면 길이: 씬별 1.9-2.0초로 제한해 전체 길이를 9.939초로 맞췄다.
- 색감 표준: 미드나잇 블루, 사파이어 블루, 웜 골드, 블랙 리플렉션을 반복 사용했다.
- 조명 표준: 로우키 시네마틱 조명, 골드 핀 조명, 반사 표면, 얕은 심도를 공통 조건으로 지정했다.
- 제품 표준: 골드 캡이 있는 사파이어 블루 LAPIS 향수병을 모든 제품 컷의 기준으로 유지했다.
- 캐릭터 표준: 동일한 한국 여성 뮤즈, 네이비 실크, 모던 한복에서 영감을 받은 실루엣, 미니멀 골드 주얼리를 반복 조건으로 사용했다.
- 프롬프트 고정어: `quiet luxury`, `deep midnight blue`, `warm gold lighting`, `cinematic low-key lighting`, `no celebrity likeness`, `no existing brand logo`를 주요 장면에 반복 적용했다.
- 원본 유지 조건: 처음에는 영상 생성 과정에서 캐릭터와 향수병이 일부 달라졌기 때문에, 이후에는 이미지 원본 유지와 제품 형태 유지 조건을 명시해 결과 일관성을 확보했다.

- 브랜드 기준: 모든 최종 산출물 이름에 `LAPIS`를 포함해 다른 과제나 브랜드 작업물과 섞이지 않도록 했다.
- 용도 기준: 스토리보드는 `storyboard_plan`, 최종 광고 영상은 `brand_ad_final`처럼 파일명만 보고 용도를 알 수 있게 했다.
- 상태 기준: 최종본은 `final`을 붙여 초안 파일과 구분했다.
- 폴더 기준: 제출용 문서와 영상은 `reports/`에 정리하고, 중간 이미지와 초안 영상은 GitHub 게시 대상에서 제외했다.
- 재사용 기준: 캐릭터와 제품을 각각 LAPIS 기준 모델로 고정해 후속 장면 제작 시 같은 브랜드 에셋으로 다시 사용할 수 있도록 했다.
- 최종 제출 파일명: `LAPIS_storyboard_plan.pdf`, `LAPIS_brand_ad_final.mp4`

## 12. 생성 소스와 사용 범위

최종 영상은 AI 생성 시각 요소와 AI 생성 음성 요소를 조합해 제작했다. 화면에 등장하는 향수병, 인물, 미스트, 조명, 공간 분위기는 직접 촬영이나 스톡 영상이 아니라 프롬프트 기반 이미지 생성과 Image-to-Video 변환을 통해 만든 결과물이다.

- 시각 요소: ChatGPT로 제품, 인물, 향수 미스트, 공간 무드 이미지를 생성하고 Google Flow에서 영상 모션으로 변환했다.
- 청각 요소: OpenAI TTS `nova` 보이스로 한국어 내레이션을 생성했다.
- 편집 요소: CapCut에서는 컷 길이 조정, 오디오 레벨 조정, 장면 연결, 최종 MP4 내보내기만 수행했다.
- 외부 소스 사용 기준: 직접 촬영 영상, 유료 스톡 영상, 유료 스톡 이미지, 기존 브랜드 광고 장면, 유명인 얼굴, 실제 상표 이미지는 사용하지 않았다.
- 참고 범위: 고급 향수 광고의 분위기와 장르적 문법은 참고했지만, 특정 브랜드의 로고, 제품명, 장면 구성, 인물 이미지를 복제하지 않았다.

## 13. 이미지 생성과 영상 변환의 역할

Text-to-Image는 정지 이미지의 콘셉트, 캐릭터, 제품 형태, 색감, 조명을 먼저 고정하는 데 사용했다. Image-to-Video는 이미 확정한 이미지의 형태를 유지하면서 짧은 움직임과 광고 리듬을 만드는 데 사용했다.

| 구분 | 역할 | 선택 이유 |
|---|---|---|
| Text-to-Image | 제품 컷, 캐릭터, 공간 무드의 기준 이미지 생성 | 브랜드 톤, 색감, 인물 스타일, 향수병 형태를 먼저 고정하기 위해 사용 |
| Image-to-Video | 기준 이미지를 짧은 모션 컷으로 변환 | 원본 이미지의 캐릭터와 제품 형태를 유지하면서 영상 광고로 확장하기 위해 사용 |

처음부터 Text-to-Video만 사용하면 캐릭터 얼굴, 의상, 향수병 형태가 장면마다 달라질 가능성이 있었다. 따라서 먼저 Text-to-Image로 LAPIS의 기준 캐릭터와 제품 이미지를 만들고, 이후 Google Flow에서 원본 이미지를 유지하는 방식으로 영상화했다.

## 14. 도구 선택 방식

도구 선택에서는 품질과 제어 가능성을 가장 우선했다. 속도와 비용도 고려했지만, 이번 과제에서는 캐릭터와 향수 제품의 일관성이 평가 품질에 직접 영향을 주기 때문에 원본 이미지 기반 영상 작업에 유리한 Google Flow를 선택했다.

- 1순위 품질: 향수 광고처럼 고급스러운 조명, 색감, 미스트, 제품 질감이 중요했기 때문에 결과물의 시각 품질을 우선했다.
- 2순위 제어: 캐릭터와 제품을 Text-to-Image로 먼저 만들고, Flow에서 원본 이미지를 유지해 영상화할 수 있다는 점을 중요하게 봤다.
- 3순위 속도: Google 유료 계정의 Flow 작업 환경을 사용할 수 있어 별도 도구 세팅 없이 빠르게 제작할 수 있었다.
- 4순위 비용: 크레딧이 제한되어 있었기 때문에 여러 영상 도구를 실험하지 않고 Flow 중심으로 제작했다. 다른 도구 비교 생성은 비용 문제로 수행하지 않았다.

Google Flow를 선택한 이유는 원본 이미지 기반 영상화에 유리했고, LAPIS 캐릭터와 향수병을 먼저 이미지로 만든 뒤 그 결과물을 영상으로 완성하는 제작 방식에 잘 맞았기 때문이다.

## 15. 편집 통합과 보정

서로 다른 도구에서 나온 결과물을 합칠 때는 브랜드 일관성, 화면 비율, 오디오 길이, 메시지 순서를 기준으로 보정했다. 각 도구의 출력물을 그대로 이어 붙이지 않고, CapCut에서 최종 광고 흐름에 맞게 컷 길이와 오디오 타이밍을 조정했다.

- 1차 선별: 생성된 컷을 확인해 인물 얼굴, 향수병 형태, 로고 텍스트, 색감이 기준에서 벗어난 컷은 편집 전에 제외했다.
- 색감 매칭: CapCut에서 컷별 밝기와 대비를 과하게 올리지 않고, 전체가 미드나잇 블루와 웜 골드 계열로 보이도록 클립 단위 색감 조정을 적용했다.
- 화면 맞춤: 모든 소스 클립을 9:16 캔버스에 맞추고, 제품이나 얼굴이 잘리는 컷은 위치와 스케일을 조정했다.
- 컷 길이 보정: 각 클립을 1.9-2.0초 단위로 자르고, 내레이션 문장이 끝나는 지점에 컷 전환이 오도록 조정했다.
- 오디오 보정: OpenAI TTS 내레이션이 장면 메시지와 맞도록 배치하고, 음성이 끊기거나 다음 컷과 과하게 겹치지 않게 볼륨과 시작 지점을 조정했다.
- 순서 보정: 제품 소개, 뮤즈, 향의 확산, 존재감 변화, 브랜드 각인의 순서를 유지해 광고 메시지가 흔들리지 않도록 했다.
- 최종 출력 확인: CapCut에서 1080x1920, 30fps, H.264/AVC, MP4A 조건으로 내보내고 최종 길이가 10초 이내인지 확인했다.

## 16. 대체 도구 사용 시 예상 변화

같은 스토리보드를 다른 영상 생성 도구로 만들 경우 가장 크게 달라질 요소는 이미지 일관성이다. 특히 캐릭터 얼굴, 향수병 형태, 로고 텍스트, 미스트 표현, 조명 질감은 도구마다 다르게 해석될 가능성이 있다.

| 관점 | Google Flow | Pika 또는 Kling 사용 시 예상 변화 |
|---|---|---|
| 품질 | 원본 이미지 기반으로 제품과 인물의 분위기를 안정적으로 유지하기 쉽다. | 장면 움직임은 풍부할 수 있지만 향수병, 로고, 얼굴 디테일이 달라질 위험이 있다. |
| 제어 | 기준 이미지를 유지해 짧은 광고 컷으로 확장하기에 적합하다. | 프롬프트 해석 폭이 커지면 같은 캐릭터와 같은 제품을 유지하기 어렵다. |
| 속도 | Google 유료 계정에서 바로 작업 가능해 세팅 시간이 적었다. | 도구를 새로 세팅하고 결과를 비교해야 하므로 작업 시간이 늘어날 수 있다. |
| 비용 | 보유한 Google 계정 크레딧 안에서 Flow 중심으로 진행했다. | 추가 유료 크레딧이 필요할 수 있어 이번 과제에서는 실제 비교 생성을 하지 않았다. |

- 캐릭터 일관성: 다른 도구를 사용하면 동일 인물처럼 보이는 정도가 달라질 수 있다.
- 제품 형태: 향수병의 비율, 골드 캡 형태, LAPIS 텍스트가 장면마다 변형될 수 있다.
- 색감: 미드나잇 블루와 웜 골드의 비율이 도구별 기본 스타일에 따라 다르게 표현될 수 있다.
- 움직임: 다른 도구에서는 카메라 움직임이나 인물 움직임이 더 과장될 수 있다.
- 대응 방법: 다른 도구를 사용할 경우에도 먼저 기준 이미지를 고정하고, `same character`, `same perfume bottle`, `preserve original image`, `no logo distortion` 같은 유지 조건을 반복해야 한다.

## 17. 짧은 버전 편집 전략

60초 버전을 15초로 줄일 때는 모든 장면을 동일하게 축소하지 않고, 브랜드 인지에 필요한 장면만 남긴다. LAPIS 광고에서는 제품, 뮤즈, 향의 사용, 브랜드 각인 장면을 우선 유지하고, 분위기 전환이나 공간 설명 장면은 줄이거나 삭제한다.

| 구분 | 60초 버전 역할 | 15초 축약 전략 |
|---|---|---|
| 제품 첫인상 | 브랜드와 제품의 세계관 소개 | 2-3초 제품 히어로 컷으로 유지 |
| 뮤즈 소개 | 타겟 인물과 스타일 설명 | 3초 이내 대표 인물 컷만 유지 |
| 향의 확산 | 향수 사용 순간과 감각 표현 | 미스트 클로즈업 3초 이내로 유지 |
| 공간 이동 | 한옥 모티프와 분위기 확장 | 필요 시 삭제하거나 1초 전환 컷으로 축소 |
| 브랜드 각인 | 제품명과 최종 메시지 전달 | 마지막 3-4초에 반드시 유지 |

메시지는 "깊은 밤의 감각", "향이 만드는 존재감", "LAPIS Eau de Parfum"의 세 단계로 재구성한다. 15초 버전에서는 설명형 내레이션을 줄이고, 제품 이미지와 브랜드명을 더 빨리 노출해 기억에 남도록 편집한다.

영상 생성 크레딧이 부족해질 경우에는 새 장면을 추가 생성하지 않고 기존 컷을 재편집하는 방식으로 대응한다.

- 씬 구성 변경: 5개 씬을 모두 새로 생성하지 않고 제품 컷, 뮤즈 컷, 엔딩 컷 3개만 유지한다.
- 도구 선택 변경: 영상 생성은 Flow에서 꼭 필요한 핵심 컷만 만들고, 나머지 분위기 전환은 CapCut의 정지 이미지 확대, 느린 줌, 디졸브 전환으로 대체한다.
- 편집 전략 변경: 미스트나 공간 이동처럼 생성 비용이 큰 장면은 짧은 디테일 컷으로 축소하고, 내레이션과 자막으로 메시지를 보완한다.
- 우선순위: 브랜드 인지에 직접 필요한 `제품 첫인상`, `향을 사용하는 인물`, `브랜드 각인`을 먼저 제작하고, 공간 설명 컷은 가장 먼저 삭제한다.
- 최종 길이: 크레딧 부족 상황에서는 10초 버전보다 더 짧은 6-8초 버전으로 줄여도 제품명과 핵심 메시지가 남도록 구성한다.
