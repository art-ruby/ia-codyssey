# Python Prompt Manager

Python과 Git의 기초를 연습하기 위해 만든 콘솔 기반 프롬프트 관리 프로그램입니다. 자주 사용하는 프롬프트를 JSON 파일에 등록하고, 전체 목록 조회·검색·추가·즐겨찾기 관리를 할 수 있습니다.

## 개발 환경

- Python 3 (검증 환경: Python 3.12.13)
- Python 표준 라이브러리 `json`, `pathlib`
- Git 및 GitHub
- 콘솔 또는 터미널

별도의 외부 패키지는 사용하지 않습니다.

## 실행 방법

1. 터미널에서 저장소 루트인 `python-prompt-manager` 폴더로 이동합니다.
2. Python 3가 설치되어 있고 `python` 명령을 사용할 수 있는지 확인합니다.
3. 다음 명령을 실행합니다.

```bash
python src/main.py
```

환경에 따라 Python 3 실행 명령이 `python3`인 경우에는 `python3 src/main.py`를 사용할 수 있습니다.

## 메뉴와 기능

프로그램을 실행하면 다음 메뉴가 반복해서 표시됩니다.

```text
========== Prompt Manager ==========
1. 전체 프롬프트 보기
2. 프롬프트 검색
3. 새 프롬프트 추가
4. 즐겨찾기 보기
5. 즐겨찾기 설정/해제
6. 종료
```

| 번호 | 메뉴 | 실제 동작 |
|---:|---|---|
| 1 | 전체 프롬프트 보기 | 모든 프롬프트의 제목, 카테고리, 즐겨찾기 여부, 내용을 출력합니다. |
| 2 | 프롬프트 검색 | 입력한 검색어가 제목, 내용 또는 카테고리에 포함된 프롬프트를 찾습니다. 영문은 대소문자를 구분하지 않습니다. |
| 3 | 새 프롬프트 추가 | 제목, 내용, 카테고리를 입력받아 추가하고 JSON 파일에 저장합니다. 하나라도 비어 있으면 추가하지 않습니다. |
| 4 | 즐겨찾기 보기 | `favorite` 값이 `true`인 프롬프트만 출력합니다. |
| 5 | 즐겨찾기 설정/해제 | 전체 목록의 번호를 입력받아 해당 프롬프트의 즐겨찾기 상태를 반대로 바꾸고 저장합니다. |
| 6 | 종료 | 현재 프롬프트 목록을 저장한 뒤 프로그램을 종료합니다. |

검색 메뉴에서는 제목, 내용, 카테고리를 한 번에 검색할 수 있으며, 목록과 검색 결과에는 각 프롬프트의 내용도 함께 표시됩니다.

## 프롬프트 데이터 구조

`prompts.json`에는 프롬프트 객체의 배열이 저장됩니다. 각 객체는 다음 네 필드로 구성됩니다.

```json
{
  "title": "프롬프트 제목",
  "content": "프롬프트 내용",
  "category": "카테고리",
  "favorite": false
}
```

- `title`: 프롬프트 제목 문자열
- `content`: 프롬프트 본문 문자열
- `category`: 카테고리 문자열
- `favorite`: 즐겨찾기 여부를 나타내는 불리언 값

## 현재 등록된 카테고리

현재 `prompts.json`에 저장된 프롬프트의 카테고리는 다음과 같습니다.

- 자동화
- 영상 생성
- 텍스트 생성
- 기타

카테고리는 코드에 고정된 선택 목록이 아닙니다. 새 프롬프트를 추가할 때 사용자가 직접 문자열을 입력하므로 다른 카테고리도 저장할 수 있습니다.

## 파일 구조

```text
python-prompt-manager/
├── .git/                                  # Git 저장소 정보
├── data/                                  # 현재 비어 있는 폴더
├── prompts/                               # 현재 비어 있는 폴더
├── src/
│   └── main.py                            # 실제 프로그램 실행 파일
├── .gitnore                               # ignore 규칙 파일(파일명 오탈자)
├── hello.py                               # Hello를 출력하는 초기 학습 파일
├── prompts.json                           # 프롬프트 데이터 파일
├── Python_Git_미션과제_제출보고서.docx    # 과제 제출 보고서
└── README.md                              # 프로젝트 설명 문서
```

`.gitignore` 파일은 현재 존재하지 않습니다. 대신 이름이 `.gitnore`인 파일이 있으며 다음 내용이 들어 있습니다.

```gitignore
__pycache__/
*.pyc
.venv/
venv/
.env
.vscode/
```

파일명이 Git이 인식하는 `.gitignore`와 다르므로 현재 이 규칙들은 자동으로 적용되지 않습니다.

## 사용한 Python 문법과 기술

- 리스트와 딕셔너리를 이용한 데이터 구성
- 함수 정의와 호출을 통한 기능 분리
- `while` 반복문과 `if`/`elif`/`else` 조건문을 이용한 메뉴 처리
- `input()`, `print()`, f-string을 이용한 콘솔 입출력
- 리스트 컴프리헨션을 이용한 검색 및 즐겨찾기 필터링
- `enumerate()`를 이용한 1부터 시작하는 목록 번호 출력
- `try`/`except`를 이용한 JSON 및 사용자 입력 오류 처리
- `pathlib.Path`를 이용한 실행 위치와 무관한 데이터 파일 경로 구성
- `json.load()`와 `json.dump()`를 이용한 JSON 읽기 및 쓰기
- `if __name__ == "__main__":` 실행 진입점

## JSON 저장 방식

`src/main.py`는 자신의 위치를 기준으로 상위 폴더의 `prompts.json` 경로를 계산하므로, 안내된 방식으로 실행하면 프로젝트 루트의 데이터 파일을 사용합니다.

- 시작할 때 `prompts.json`을 UTF-8로 열고 `json.load()`로 목록을 불러옵니다.
- 파일이 없으면 코드에 정의된 기본 프롬프트 3개를 `prompts.json`에 저장한 뒤 사용합니다.
- JSON 형식이 잘못되었거나 파일 읽기 오류가 발생해도 기본 프롬프트 3개로 파일을 다시 저장합니다.
- 새 프롬프트 추가, 즐겨찾기 변경, 메뉴 6번을 통한 정상 종료 시 현재 전체 목록을 저장합니다.
- 저장할 때 `ensure_ascii=False`와 `indent=2`를 사용하여 한글을 그대로 유지하고 들여쓰기된 JSON을 작성합니다.

현재 파일은 유효한 JSON이며 프롬프트 4개가 저장되어 있습니다. 추가 및 즐겨찾기 변경에 따른 JSON 저장도 실제로 작동합니다.

## Git 및 GitHub 활용

- 현재 브랜치: `main`
- GitHub 원격 저장소: <https://github.com/art-ruby/python-prompt-manager.git>
- `origin`이 위 주소의 fetch 및 push 원격으로 설정되어 있습니다.

최근 커밋에는 Hello Python 실행, README와 ignore 파일 추가, 기본 프롬프트 등록, 메뉴 기능 추가, JSON 저장 및 즐겨찾기 기능 완성 과정이 순서대로 기록되어 있습니다. 이를 통해 기능을 단계적으로 구현하고 변경 이력을 Git으로 관리했습니다.

## 사용 시 주의사항

- 프로그램은 콘솔 입력 방식이므로 메뉴 번호 `1`부터 `6`까지 입력해야 합니다.
- 즐겨찾기 변경 번호는 전체 프롬프트 목록에 표시된 번호를 기준으로 합니다.
- 프롬프트 추가 시 제목, 내용, 카테고리를 모두 입력해야 합니다.
- 카테고리는 정해진 선택지가 아니라 직접 입력하는 값이므로 표기가 달라질 수 있습니다.
- 저장은 `prompts.json` 전체 내용을 덮어쓰는 방식입니다. 중요한 데이터가 있다면 실행 전에 별도로 백업해야 합니다.
- 손상된 JSON을 실행하면 코드의 기본 프롬프트 3개로 파일이 다시 작성될 수 있습니다.
- 현재 `.gitignore`가 없고 `.gitnore`만 있으므로 캐시, 가상 환경, 환경 변수 파일 등이 Git에서 자동 제외되지 않습니다.
- 터미널에서 한글이 깨져 보인다면 UTF-8을 지원하는 터미널과 글꼴을 사용해야 합니다.

## 과제 수행 결과와 배운 점

이 과제를 통해 콘솔 메뉴를 반복 실행하고 사용자 입력에 따라 기능을 분기하는 방법을 익혔습니다. 프롬프트를 리스트와 딕셔너리로 표현하고, 검색·추가·즐겨찾기 기능을 함수로 나누어 구현했습니다. 또한 JSON 파일을 읽고 변경 내용을 다시 저장하여 프로그램을 종료한 뒤에도 데이터를 유지하는 방법과 예외 처리의 필요성을 확인했습니다.

Git 커밋으로 구현 단계를 기록하고 GitHub 원격 저장소를 연결하면서 로컬 변경 이력과 원격 저장소를 함께 관리하는 기본 흐름도 연습했습니다. 현재 프로그램은 전체 조회, 통합 검색, 추가, 즐겨찾기 조회 및 변경 기능을 제공합니다.
