# 경제 뉴스레터 자동화 과제

이 폴더는 방금 제시한 지시서 기준의 경제 뉴스레터 자동화 과제 산출물만 포함한다.

## 산출물 위치

전체 구현 파일은 [economic-news-automation](C:/ia-codyssey/assignments/03-nocode-automation-workflow/economic-news-automation)에 정리했다.

## 포함 내용

- Make HTTP Webhook 자동화 구현 가이드
- n8n HTTP Webhook 자동화 import JSON
- n8n 핫이슈 감지 워크플로우 import JSON
- Gmail Trigger 전환 버전
- Google Sheets 구조와 CSV 샘플
- HTTP 테스트 요청과 예상 결과
- Make vs n8n 비교 보고서
- 프로젝트 2 핫이슈 감지 설계 보고서
- 최종 제출 보고서
