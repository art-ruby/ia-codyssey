# 스크린샷 첨부 가이드

최종 보고서에 실제 캡처를 첨부할 때 아래 항목을 순서대로 저장한다. 인증값, 이메일 주소, Webhook URL, Sheet ID는 반드시 가린다.

## n8n

- 프로젝트 1 전체 캔버스
- 프로젝트 2 전체 캔버스
- Webhook 노드 설정
- Code 노드 실행 결과
- Google Sheets Add Row 매핑
- 중복 메시지 응답 결과
- 핫이슈 응답 결과

## Make

- Custom Webhook 설정
- Router 전체 화면
- 경제전문/종합시사/미분류 Filter 설정
- Tools Set Variables 매핑
- Google Sheets Add a Row 매핑
- Webhook Response 설정
- Error Handler 설정

## Google Sheets

- 뉴스수집 시트 샘플 행
- 핫이슈 시트 샘플 행
- 오류로그 시트 헤더
