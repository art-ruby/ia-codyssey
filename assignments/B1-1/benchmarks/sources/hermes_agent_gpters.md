## 사용 원칙

- 콘텐츠의 전개 방식은 벤치마킹할 수 있지만 원문 문장을 길게 복제하지 않는다.
- 사례와 평가는 작성자에게 명확히 귀속한다.
- 숫자, 설치 명령, 모델명, 라이선스는 게시 직전에 공식 출처로 재검증한다.
- Hermes와 OpenClaw 비교는 한쪽 커뮤니티 글만으로 확정하지 않는다.
- 첨부 이미지가 없는 상태이므로 페이지 이미지를 저장소에 복제하지 않는다.
