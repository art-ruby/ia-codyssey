## 실제 AI 답변 확인 (따로 기록)
- 실제 Hermes(`gpt-6-luna`), 브라우저(테스트 서버, 실제 Firestore, 표본 모드)에서 3문항.
  - q01 '정산 API는 언제 종료돼?': 근거 1건(정산 API 종료 공지, 본문 확인), 원문 요약에 종료일, 확인 안 된 숫자 없음.
  - q10 '결제 개편과 관련된 자료를 모아 줘': 근거 4건(기대 자료 2건 포함), 원문 요약과 해석 분리, 해석에서 한 자료의 관계를 '확정된 것으로 볼 수 없다'고 표시. 관련 자료 제안·확정 연결은 이번 답에 없었다.
  - n03 '화성 탐사선 발사 일정은 언제야?'(q01에 이어지는 대화): 첫 두 번은 `invalid_output` — 과거 답을 문장으로 보내 모델이 문장으로 답했다(재현 확인: 과거 답 문장일 때 33자 문장 응답, 과거 답 없을 때 JSON). 과거 답을 JSON 형식으로 보내고 규칙을 보강한 뒤 같은 대화에서 정상: 한계 '근거가 되는 보관 자료를 찾지 못했습니다.' 첫 줄, 근거 0건, 원문 요약은 '찾지 못했다', 해석은 범위를 좁힐 정보를 요청.
- 한계: 실제 모델 답의 사실성은 사람이 위 3문항만 읽어 확인했다. 13문항 전체의 실제 답 품질은 측정하지 않았다(비용).
