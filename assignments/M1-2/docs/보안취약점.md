- [x] 11. 🟡 `Authorization` 헤더가 아닌 쿼리스트링·URL로 토큰을 받지 않는다. (로그·리퍼러에 남음)

- [ ] 14. 🟢 로그아웃 후 브라우저에 토큰이 남지 않는다.

## E. CORS·HTTP 보안 헤더

- [x] 28. 🔴 `ALLOWED_ORIGINS`에 `*`가 없고 실제 웹 도메인만 정확히 적혀 있다. `allow_credentials`와 `*`를 함께 쓰지 않는다.
- [ ] 29. 🟡 HTTPS만 사용한다. HTTP 접근은 리다이렉트된다. (Render·Vercel 기본 제공 확인)
- [x] 30. 🟡 웹에 보안 헤더가 있다: `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `X-Frame-Options`(또는 `frame-ancestors`). Vercel `vercel.json`의 `headers`로 설정한다.
- [ ] 31. 🟢 `uvicorn`을 `0.0.0.0`으로 여는 것은 Render 배포에서만이고, 로컬은 `127.0.0.1`로 제한한다.

## F. 웹 프런트엔드 (바닐라 JS)

- [x] 32. 🔴 XSS: 저장된 자료 제목·본문·메모·AI 응답을 `innerHTML`로 넣지 않는다. `textContent`를 쓰거나 새니타이즈한다. (`web/js/views/*.js` 전체 검색)
- [x] 33. 🔴 AI가 만든 마크다운·링크를 렌더링할 때 `javascript:` 같은 위험한 URL 스킴을 걸러낸다.
- [x] 34. 🟡 외부 링크는 `rel="noopener noreferrer"`와 `target="_blank"`를 함께 쓴다.
- [x] 35. 🟡 토큰·개인 데이터를 `localStorage`에 장기 보관하지 않는다. (Firebase SDK 기본 저장 외)
- [x] 36. 🟡 `config.js`에는 공개 가능한 값(Firebase Web API 키, 도메인, 프로젝트 ID)만 있다. 비밀값이 섞이지 않았다.
- [ ] 37. 🟡 Firebase Web API 키에 HTTP 리퍼러 제한을 걸었다. (Google Cloud Console)
- [ ] ⚠ 38. 🟢 외부 CDN 스크립트를 쓴다면 버전 고정과 SRI(`integrity`)를 적용한다.
