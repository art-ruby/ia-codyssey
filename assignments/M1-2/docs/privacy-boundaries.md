# 개인정보와 권한 경계

## 사용 가능한 자료

- 사용자가 직접 붙여넣은 공개 기사 텍스트
- 사용자가 입력한 관심 키워드
- 공개된 뉴스 출처 이름과 링크

## 비식별화가 필요한 자료

- 기사 속에 포함된 제3자의 연락처나 개인정보
  → 브리핑에 포함하지 않거나, 역할만 표시 (예: "A사 대표")

## 저장하면 안 되는 정보

- 비밀번호, API 키, 인증 토큰
- 주민등록번호, 여권번호 등 신분 식별 정보
- 정확한 주소, 전화번호
- 가족·고객의 실명
- 원본 금융 정보 (계좌번호, 카드번호 등)

## 외부 전송 전에 확인할 것

- 브리핑 내용을 다른 사람이나 서비스에 보내기 전에 반드시 사용자 확인
- 외부 API 호출이나 서비스 연결은 사용자가 명시적으로 요청한 경우에만
- 공유 전에 민감정보가 포함되지 않았는지 한 번 더 점검

## 삭제와 보관에 대한 기본 원칙

- 브리핑 결과는 로컬 파일로만 보관하고, 자동으로 외부에 업로드하지 않음
- 더 이상 필요 없는 원본 텍스트는 사용자가 직접 삭제
- 프로젝트 폴더 안의 파일은 사용자가 관리 주체
