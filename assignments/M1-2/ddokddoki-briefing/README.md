# 똑똑이 - AI·기술 뉴스 브리핑 비서

## 이 비서가 해결할 문제

AI·기술 분야 소식을 여러 곳에서 따로 찾아봐야 해서 번거롭고,
바쁜 날에는 중요한 트렌드를 놓치는 일이 반복됩니다.
똑똑이는 흩어진 소식을 모아서 읽기 쉬운 마크다운 브리핑으로 정리해 줍니다.

## 이번 주 작은 성공 기준

- AI·기술 키워드나 기사 텍스트를 넣으면, 핵심만 정리한 마크다운 브리핑 1건을 만들 수 있다.
- 브리핑을 읽고 "오늘 뭐가 중요한지 30초 안에 파악할 수 있다"고 느끼면 성공.

## 예상 입력과 결과

### 입력 예시

- 관심 키워드: "Claude 신기능", "오픈소스 LLM", "AI 에이전트"
- 복사한 기사 텍스트 또는 뉴스 링크 목록

### 결과 예시

```markdown
# 오늘의 AI 브리핑 (2026-09-29)

## 주요 소식
- **Claude 신기능 출시**: 새로운 도구 사용 기능이 추가됐어요. (출처: Anthropic 블로그)
- **오픈소스 LLM 동향**: Llama 계열 모델이 벤치마크에서 좋은 성적을 냈어요.

## 눈여겨볼 점
- 에이전트 기반 자동화가 빠르게 확산되고 있어요.

## 한줄 요약
> 이번 주는 에이전트 기능 확장이 가장 큰 흐름이에요!
```
