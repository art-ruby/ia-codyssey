# 기능 아이디어 씨앗

## 해결할 문제

AI·기술 뉴스를 여러 곳에서 따로 찾아봐야 해서 시간이 들고, 중요한 소식을 놓친다.

## 지금 사람이 하는 과정

1. 여러 사이트나 SNS를 돌아다니며 기사를 찾는다.
2. 눈에 띄는 기사를 열어서 읽는다.
3. 중요한 내용을 머릿속에 기억하거나 메모한다.
4. 나중에 다시 찾으려면 어디서 봤는지 기억이 안 난다.

## 기능 후보

### 후보 1: 기사 텍스트 → 브리핑 정리

| 항목 | 내용 |
|------|------|
| **입력** | 복사한 기사 텍스트 1~5건 |
| **처리** | 각 기사의 핵심 내용을 뽑아서 분야별로 분류 |
| **결과** | 마크다운 브리핑 문서 (주요 소식, 눈여겨볼 점, 한줄 요약) |

### 후보 2: 키워드 기반 관심사 정리

| 항목 | 내용 |
|------|------|
| **입력** | 관심 키워드 목록 (예: "AI 에이전트", "오픈소스 LLM") |
| **처리** | 키워드와 관련된 내용을 입력된 기사에서 찾아 분류 |
| **결과** | 키워드별로 정리된 마크다운 문서 |

## 가장 작은 첫 테스트

**후보 1**로 시작합니다.

1. AI·기술 관련 기사 1~2건의 텍스트를 복사해서 똑똑이에게 전달한다.
2. 똑똑이가 마크다운 브리핑을 만들어 준다.
3. 결과를 읽어본다.

## 성공 여부를 판단할 관찰 기준

- [ ] 브리핑을 30초 안에 읽고 핵심을 파악할 수 있는가?
- [ ] 원문의 중요한 내용이 빠지지 않았는가?
- [ ] 원문의 뜻이 왜곡되지 않았는가?
- [ ] 읽기 편한 구조(항목, 제목, 한줄 요약)로 되어 있는가?
- [ ] "다시 찾아보고 싶은 기사"를 출처와 함께 확인할 수 있는가?
