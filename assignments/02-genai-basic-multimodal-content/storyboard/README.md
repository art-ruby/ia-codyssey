# LAPIS Eau de Parfum Storyboard

이 폴더는 2번 과제 `02-genai-basic-multimodal-content`의 LAPIS Eau de Parfum 광고 스토리보드 자료를 보관한다.

## 관련 파일

- `스토리보드.png`: 구글 플로우가 제안한 3x3 비주얼 스토리보드 이미지
- `롱폼1.png`: 롱폼 콘텐츠용 이미지
- `쇼츠1.png`: 쇼츠 콘텐츠용 이미지 1
- `쇼츠2.png`: 쇼츠 콘텐츠용 이미지 2
- `1.jpg`: 참고 이미지

## 구글 플로우 제안 스토리보드

### 기본 형식

- 주제: `LAPIS Eau de Parfum` 광고
- 화면비: 9:16
- 구성: 3x3 그리드, 총 9개 패널
- 사용 패널: 첫 5개 패널만 스토리보드 장면으로 사용
- 나머지 패널: 은은한 추상 블루 텍스처로 처리
- 구분선: 각 패널 사이에 얇은 테두리 또는 디바이더 적용

## 활성 프레임 5개

### Panel 1

사파이어 블루 향수병과 골드 캡의 매크로 클로즈업.  
골드 캡에 빛이 반사되고, 어두운 추상 배경에는 골드 마블 질감이 들어간다.

### Panel 2

낮은 번 헤어를 한 우아한 여성이 현대적인 네이비 시스루 레이어드 한복을 입고 있다.  
어두운 블루 배경 앞에서 옆모습으로 고개를 돌리는 중간 거리 샷이다.

### Panel 3

여성의 목과 향수병을 극단적으로 가까이 보여주는 클로즈업.  
푸른 스포트라이트 속에서 미세한 향수 미스트가 반짝인다.

### Panel 4

반투명 네이비 한복을 입은 여성이 우아하게 걸어가는 전신 샷.  
빛의 흔적이 뒤따르고, 어두운 공간에는 맥동하는 골드 마블 패턴이 보인다.

### Panel 5

어두운 반사 표면 위에 사파이어 블루 LAPIS 향수병을 중앙에 배치한 제품 컷.  
공중에는 골드 입자가 떠 있고, 배경에는 우아한 골드 텍스트 `LAPIS`가 보인다.
