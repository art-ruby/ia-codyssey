# GenAI 기초 2: 멀티모달 콘텐츠 제작

## 1. 과제 주제

- 브랜드명: Lapis
- 제품: 프리미엄 향수
- 현재 확정 범위: 캐릭터 설정
- 캐릭터명: The Muse of Lapis

스토리보드, 씬 구성, 영상 프롬프트, 오디오 프롬프트는 아직 확정하지 않는다. 이후 별도 제작한다.

## 2. 캐릭터 설정 반영 문서

- 캐릭터/브랜드 가이드: `brand/brand_identity.md`

## 3. 캐릭터 방향 요약

The Muse of Lapis는 20대 후반에서 30대 초반의 한국인 여성으로, 화려함보다 조용한 고급감과 지적인 눈빛을 가진 인물이다.

핵심 키워드:

- Quiet Luxury
- Glass Skin
- 뮤트 톤 메이크업
- 미세한 블루 펄 아이 디테일
- 다크 브라운 긴 생머리 또는 로우 번
- 딥 네이비 실크 슬립 드레스
- 현대적으로 재해석한 한복 저고리 실루엣의 오간자 자켓
- 미니멀 골드 주얼리
- 라피스 라줄리 팔찌

## 4. 참고 자료 사용 원칙

- 첨부 향수 이미지는 고급 향수 광고의 무드 참고로만 사용한다.
- 참고 영상은 전통미와 현대적 럭셔리, 사운드 연출, 모델 분위기 분석용으로만 사용한다.
- Chanel, N°5, 기존 병 디자인, 특정 배우의 얼굴은 직접 복제하지 않는다.

## 5. 향후 작성 예정

- `storyboard/` - 스토리보드 확정 후 작성
- `prompts/` - 이미지, 비디오, 오디오 프롬프트 확정 후 작성
- `reports/` - 제작 계획과 결과 보고서 작성
- `outputs/` - 생성 결과물 저장
