# [Project A] 브랜드 아이덴티티 생성기

## 메타데이터

- 분야: AI 활용 학습
- 구분: Term Project
- 학습시간: 40시간

## 1. 미션 소개

브랜드 디자인 외주비가 수백만 원에서 시작하는 이유가 있습니다. 네이밍, 슬로건, 컬러, 로고까지 하나하나가 전문 작업이기 때문입니다.

그 작업을 브리프 하나로 자동화할 수 있다면 어떨까요.

LLM API로 텍스트 브랜드 요소를 생성하고, 이미지 생성 API로 로고 시안까지 뽑는 CLI 프로그램을 완성합니다.

브랜드 디자인은 네이밍, 슬로건, 스토리, 컬러, 로고 등 다양한 요소를 종합적으로 기획해야 하는 작업입니다. 외주 플랫폼에서 브랜드 디자인 외주가 활발한 이유도 이 작업이 시간과 전문성을 요구하기 때문입니다.

이 미션에서는 브랜드 브리프(업종, 타겟, 키워드 등)를 입력하면 AI가 브랜드 네이밍, 슬로건, 스토리, 컬러 팔레트, 로고 시안까지 자동 생성하는 CLI 프로그램을 구현합니다.

LLM API로 텍스트 기반 브랜드 요소를 생성하고, 이미지 생성 API로 로고 시안을 만든 뒤, 모든 결과물을 폴더에 저장합니다.

## 2. 최종 결과물

다음 기능이 정상 동작하는 CLI 기반 Python 프로그램 1개를 완성한다.

### 브랜드 브리프 입력

JSON 파일로 브랜드 정보(업종, 타겟, 키워드, 톤앤매너 등)를 입력받는다.
AI 기반 브랜드 요소 생성
브랜드 네이밍 후보 3~5개와 각각의 의미
슬로건/태그라인 3개
브랜드 스토리(탄생 배경, 철학)
브랜드에 어울리는 컬러 팔레트(메인/서브 컬러)
AI 기반 로고 시안 생성
이미지 생성 API를 활용하여 로고 시안 2~3개를 PNG 파일로 저장
결과 저장
모든 텍스트 결과를 JSON 파일로 저장
컬러 팔레트를 시각화하여 PNG 이미지로 저장
로고 시안을 PNG 이미지로 저장

## 4. 기능 요구 사항

다음 요구사항을 모두 만족해야 한다.

### 사용자 입력

print와 input을 사용하여 대화형으로 정보를 입력받는다.
필수 입력: 브리프 파일 경로
선택 입력: 출력 폴더 경로 (기본값: ./output)
브랜드 브리프 입력
JSON 파일로 브랜드 정보를 입력받는다.
필수 필드: 업종(industry), 타겟(target), 키워드(keywords)
선택 필드: 톤앤매너(tone), 경쟁사(competitors), 추가 요청사항(notes)
브랜드 네이밍 생성
LLM API를 호출하여 브랜드명 후보 3~5개를 생성한다.
각 네이밍에 대한 의미/유래 설명을 함께 생성한다.
슬로건 생성
LLM API를 호출하여 슬로건/태그라인 3개를 생성한다.
브랜드 톤앤매너에 맞는 문구를 생성한다.
브랜드 스토리 생성
LLM API를 호출하여 브랜드 스토리(300자 내외)를 생성한다.
브랜드의 탄생 배경, 철학, 비전을 포함한다.
컬러 팔레트 생성
LLM API를 호출하여 브랜드에 어울리는 컬러를 추천받는다.
메인 컬러 1개, 서브 컬러 2~3개를 HEX 코드로 받는다.
matplotlib 등 다양한 방법으로 컬러 팔레트를 시각화하여 PNG로 저장한다.
로고 시안 생성
이미지 생성 API(DALL-E 등)를 호출하여 로고 시안 2~3개를 생성한다.
생성된 이미지를 PNG 파일로 저장한다.
결과 저장
출력 폴더에 모든 결과물을 저장한다.
텍스트 결과는 brand_result.json으로 저장한다.
이미지 파일은 개별 PNG로 저장한다.
에러 처리
API 호출 실패 시 에러 메시지를 출력하고 다음 단계를 계속 진행한다.
API 키가 없거나 잘못된 경우 명확한 안내 메시지를 출력한다.
API 키 관리
* API 키를 코드에 직접 작성하지 않는다.
* 환경 변수 또는 설정 파일에서 API 키를 읽어온다.
