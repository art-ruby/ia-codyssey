# 사용법

이 프로그램을 어떻게 쓰는가. **이 문서 하나만 읽어도 쓸 수 있게** 적는다.
코드를 고치려면 [tech.md](tech.md), 왜 이렇게 만들었는지는 [prd.md](prd.md).

---

## 이 프로그램이 하는 일

일본 유튜브 롱폼(10분 이상) 중에서 **작은 채널인데 유난히 잘 된 영상**을
매일 찾아낸다. 찾은 소재는 Claude 웹에 붙여넣을 한 장으로 뽑아 준다.

**프로그램이 대본을 쓰지 않는다. 재료만 모아 준다.**

```
Radar      기회를 찾는다      ← 이 프로그램
Claude     대본을 쓴다
automaker  영상을 만든다
```

두 채널 관점으로 같은 데이터를 읽는다.

```
🛡️ 제도와 현실의 덫       몰라서 손해 보는 정년 전후의 돈·제도·집·간병
🍂 정년 후 고독과 자존감    직함 상실·재취업 냉대·황혼이혼·소규모 벌이
```

## 1. 화면 열기

```
앱실행.cmd  ← 두 번 클릭
```

브라우저가 `http://127.0.0.1:8502` 로 열린다.

> **검은 창은 켜 둔 채로 둔다.** 닫으면 화면도 꺼진다.
> 끄고 싶으면 검은 창을 닫으면 된다.

## 2. 아침 5분 — 소재 고르기

`☀️ 오늘의 발견` 탭 하나면 된다.

```
① 맨 위에서 채널 고르기
   [전체]  [🛡️ 제도와 현실의 덫]  [🍂 정년 후 고독과 자존감]

② 🔥 지금 오르는 중  10건 훑기
③ 🆕 어제 새로 들어온 것  10건 훑기
④ 마음에 드는 행의 [열기] → 유튜브에서 실제 영상 확인
⑤ 쓸 만하면 아래 [한 장 만들기] → 글 상자 오른쪽 위 복사 아이콘 → Claude 웹
```

여기까지가 «고르는» 일이다. 보통 5분이면 끝난다.

### 두 목록의 차이 — 헷갈리면 안 된다

| | 뜻 | 믿을 만한가 |
|---|---|---|
| 🔥 지금 오르는 중 | 같은 영상을 두 시점에 봤더니 조회수가 늘었다 | **확실하다.** 두 관측을 뺀 값이라 착각할 여지가 없다 |
| 🆕 어제 새로 들어온 것 | 검색에 **어제 처음 걸렸다** | 주의. «어제 떴다» 가 아니다 |

②가 비어 있으면 정상일 수 있다. 증가량은 **관측이 6시간 넘게 벌어져야** 나온다.
방금 모은 영상은 아직 한 번밖에 못 봤다.

③은 한 달 전에 이미 터진 영상이 이제야 검색에 걸린 것일 수 있다.
그래서 **게시 후 며칠** 을 함께 띄우고, 30일 넘은 것은 따로 세어 준다.

### 표에서 보는 숫자

| 칸 | 뜻 |
|---|---|
| 점수 | Video Score — 같은 나이대 안에서 얼마나 강한가 (0~100) |
| 구독자 / 영상수 | 채널 크기. **구독 4,190에 영상 4편**과 **구독 4,190에 671편**은 전혀 다른 채널 |
| 구독대비 | 조회수 ÷ 구독자. 5배 넘으면 눈여겨본다 |
| 게시 후 | 며칠 됐나 |
| 열기 | 유튜브로 바로 |

> 구독자 1,000명 미만은 **구독대비를 계산하지 않는다.** 구독 6명이 1,461회를
> 받으면 244배가 되는데, 그것은 «잘 됐다» 가 아니라 «구독자가 없다» 는 뜻이다.

## 3. 만들기로 정했으면

같은 탭 아래 `🎬 제작 후보로 확정하기`.

```
⑥ 어느 채널에서 만들지 고르기
⑦ [댓글 받고 브리프 만들기]        1~2분 걸린다
⑧ Channel Fit 7개 항목 + 브리프 읽기
⑨ [Claude 대본용 자료 만들기] → 복사 → Claude 웹
⑩ 나온 대본을 data/scripts/{채널}/ 에 저장
```

⑦에서 일어나는 일 — 댓글 50개 수집 → 시청자가 실제로 뭘 걱정하는지 분석 →
이 채널에서 만들 가치가 있는지 판정 → 브리프 조립.

### Channel Fit 읽는 법

**HIGH / MEDIUM / LOW 와 근거 문장만 있다. 점수는 없다.**
0~100 으로 만들면 없는 정밀도를 꾸며 내기 때문이다.

| 항목 | 묻는 것 |
|---|---|
| 시청자 적합 | 50~69세에게 직접 관련되나 |
| 채널 관련성 | 이 채널 약속과 이어지나 |
| 돈 영향 | 시청자의 돈·비용·자산에 영향이 있나 |
| 문제 강도 | «모르면 손해» 같은 분명한 문제가 있나 |
| 롱폼 가능성 | 15~30분을 채울 층이 있나 |
| 뉴스 의존 | 금방 낡나 (**높을수록 나쁘다**) |
| 오래 감 | 1년 뒤에도 같은 고민이 있나 |

두 채널 모두 관련성 HIGH 면 **CROSSOVER** 다. 양쪽 브리프를 각각 만들 수 있다.
다만 **같은 내용을 제목만 바꿔 두 채널에 올리면 안 된다.**

### ⚠️ FACT CHECK

대본에 `[FACT CHECK]` 표시가 붙은 것은 **확인 전에 영상으로 만들지 않는다.**

보는 사람이 50~69세이고 다루는 것이 자기 연금·세금·집이다.
틀린 제도 설명은 조회수 문제가 아니라 **사람에게 실제 손해를 끼친다.**

## 4. 데이터는 알아서 쌓인다

매일 **아침 7시** 에 윈도우 작업 스케줄러가 수집한다. 손댈 것이 없다.

확인은 `⏰ 자동 실행` 탭에서. 마지막 실행 시각과 결과(0이면 성공)가 보인다.

직접 돌리고 싶으면 터미널에서

```
python -m src.snapshot_collector      조회수만 갱신 · 약 18 units
python -m src.collector               새로 검색 · 약 2,400 units
```

> 수집은 하루 한 번이면 된다. 같은 날 두 번째는 프로그램이 막는다
> (정말 필요하면 `--force`).

## 5. 나머지 탭은 언제 보나

| 탭 | 언제 |
|---|---|
| 🔥 떡상영상 | 점수 상위를 한 번에 보고 싶을 때 |
| 📈 시계열 | 주차별 흐름. **개별 영상이 아니라 그 주에 게시된 것들의 평균** |
| 🎯 Outlier 분포 | 구독자 대비 조회수 산점도. 왼쪽 위가 우리가 찾는 것 |
| 📊 데이터 | 전체 표 · CSV 내려받기 |
| 🔎 검색어 관리 | 일주일에 한 번. 성과 낮은 검색어 빼고 새 후보 넣기 |
| 🏆 채널 검증 | 영상이 아니라 **채널이** 오르는지 |
| 📋 Watchlist | 몇 건을 추적 중인지 |
| 📶 수집·할당량 | 오늘 얼마나 썼나 |
| ⏰ 자동 실행 | 스케줄러가 도는지 |
| 🌐 번역 설정 | 제목 한글화가 되는지 |

### 검색어 관리를 일주일에 한 번 보는 이유

검색어를 고정해 두면 **일주일쯤 뒤 같은 영상만 나온다.**

화면이 **이상치 수로** 줄을 세워 준다 — 중앙 점수가 아니다. 우리가 찾는 것은
«평균이 높은 주제» 가 아니라 «유난히 잘 된 영상» 이라서다.
영상 15건 이상 모았는데 이상치가 0건인 검색어를 «뺄 후보» 로 짚어 준다.

지금 쓰는 검색어 12개:

```
🛡️ 제도와 현실의 덫
   定年後 住民税              정년 후 주민세
   実家 空き家 処分            본가 빈집 처분
   在職老齢年金 減額            재직노령연금 감액
   定年後 健康保険料            정년 후 건강보험료
   マンション 修繕積立金 値上げ      맨션 수선적립금 인상
   介護離職 後悔              개호이직 후회

🍂 정년 후 고독과 자존감
   定年後 孤独               정년 후 고독
   60代 再就職 現実           60대 재취업 현실
   熟年離婚                 황혼이혼
   濡れ落ち葉 夫              «젖은 낙엽» 남편
   孤独死 一人暮らし            고독사·혼자 살기

## 6. 안 될 때

| 증상 | 이유와 조치 |
|---|---|
| 브라우저가 안 열림 | 검은 창에 뜬 주소를 직접 붙여넣는다 |
| 「지금 오르는 중」이 빔 | 관측이 6시간 넘게 안 벌어졌다. **정상이다** |
| 채널을 골랐더니 0건 | 그 채널 검색어로 아직 수집을 안 했다. `python -m src.collector` |
| 숫자가 어제 그대로 | `⏰ 자동 실행` 탭에서 마지막 실행·결과 확인 |
| 자막이 「없음」 | 「요청이 몰려 잠시 막혔습니다」면 조금 뒤 다시. 진짜 없는 것과 구분해 적는다 |
| 브리프에 Channel Score 「판정 못 함」 | 점수가 낮은 게 아니라 **비교할 과거 영상이 모자란 것** |
| 코드를 고쳤는데 안 바뀜 | 검은 창 닫고 `앱실행.cmd` 다시 두 번 클릭 |
| 「할당량을 다 썼습니다」 | 태평양시 자정(한국시간 **오후 4시**)에 초기화된다 |

## 7. 조심할 것

```
화면을 만지는 것만으로는 돈이 안 나간다.
   필터·탭 이동은 저장된 CSV 만 읽는다.
   API 를 부르는 것은 [한 장 만들기] [댓글 받고 브리프 만들기] 뿐이다.

숫자가 말이 안 되게 크면 성공이 아니라 버그다.
   실제로 +16,162%, 2,941배, 244배가 나온 적이 있다. 전부 계산이 틀린 것이었다.

.env 파일은 절대 공유하지 않는다.
   API 키가 들어 있다.
```

```

data/briefs/{채널}/            만들어진 브리프
data/scripts/{채널}/           Claude 가 쓴 대본 (직접 저장)
data/raw/videos.csv           모은 영상
data/config/channels.json     두 채널의 정체성
data/raw/seeds.json           검색어

mockup/index.html             옛 화면 목업 (보관용 · 동작 안 함)
