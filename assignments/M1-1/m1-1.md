# AI 데이터 분석: 데이터 기반 트렌드 분석

## 1. 미션 소개

그래프를 그리는 건 어렵지 않습니다. 어려운 건 그게 무슨 의미인지 해석하는 일입니다.

숫자가 올라가는 이유, 특정 시점에 꺾이는 이유 — 데이터는 스스로 말하지 않습니다. 읽어내야 합니다.

시계열 데이터에서 패턴을 발견하고 "그래서 이게 무슨 의미인가"를 스스로 해석하는 과정을 경험합니다.

데이터는 그 자체로는 의미가 없습니다. 데이터를 정제하고, 시각화하고, 패턴을 발견해야 비로소 의사결정에 활용할 수 있는 인사이트가 됩니다.

주식 가격의 흐름, 기온 변화, 판매량 추이처럼 시간에 따라 변화하는 데이터를 시계열 데이터라고 합니다.

시계열 분석을 통해 과거의 패턴을 파악하고, 미래를 예측하며, 이상 징후를 감지할 수 있습니다.

이 미션에서는 시계열 데이터를 분석하고 인사이트 리포트를 작성합니다.

어떤 데이터를 분석할지, 어떤 질문을 던질지, 결과를 어떻게 해석할지에 집중합니다.

단순히 그래프를 그리는 것이 아니라, 데이터에서 의미 있는 패턴을 발견하고 "그래서 이게 무슨 의미인가?"를 스스로 해석하는 과정을 경험합니다.

이 경험은 데이터 기반 의사결정의 기초가 되며, AI를 활용한 분석 역량을 기르는 데 핵심이 됩니다.

## 2. 최종 결과물

다음 조건을 만족하는 분석 결과물 1개를 완성한다.

### 분석 리포트 (Markdown)

### 입력/자료: 선택한 시계열 데이터(최소 100개 이상 데이터 포인트)

출력/형식: REPORT.md에 분석 주제, 질문, 데이터 설명, 시각화, 인사이트, 결론/한계점을 포함
시각화 결과물 (리포트 내 포함)
필수: 시각화 2개 이상
권장: 추가 1개 이상(총 3개 이상)
출력/형식: 이미지 파일(png 등) 또는 노트북 출력 캡처를 리포트에 포함(링크 정상 동작)
Python 코드
입력/자료: 원본 데이터 파일 또는 수집 스크립트
출력/형식: Jupyter Notebook(.ipynb) 또는 Python 스크립트(.py)
GitHub 저장소
포함: 코드, 리포트, (가능한 범위 내) 데이터 또는 데이터 수집 방법 문서

## 3. 과제 목표

이 과제를 마친 후, 학습자는 아래를 스스로 설명할 수 있어야 한다.

### 데이터 분석 사고

데이터를 보고 “무엇을 알고 싶은지(질문)”를 3개 이상 정의할 수 있다.
결측치/이상치가 무엇이며, 어떤 기준으로 처리했는지 설명할 수 있다.
그래프에서 확인한 사실(관찰)과 해석(가설)을 구분해 말로 설명할 수 있다.
시계열 데이터 이해
시계열의 트렌드/계절성/노이즈 개념을 설명할 수 있다.
이동평균, 변화율 등 기본 시계열 분석 기법을 왜/어떻게 적용했는지 설명할 수 있다.
AI 활용 역량
분석 목적에 맞는 질문을 AI에게 던지고, 생성된 코드/해석을 검증할 수 있다.
AI 도움을 받더라도 최종 판단(해석/결론)은 본인이 근거를 들어 설명할 수 있다.

## 4. 기능 요구 사항

다음 요구사항을 모두 만족해야 한다.

### 분석 주제 및 데이터 선정

관심 있는 시계열 데이터 1개를 선정한다. (예: 주식/암호화폐 가격, 기온/날씨, 판매량, 환율, 조회수 등)
최소 100개 이상의 데이터 포인트를 포함한다.
데이터 출처(예: 공공데이터포털, Kaggle, Yahoo Finance 등)와 기간을 명시한다.
분석 질문 설정
데이터를 통해 답하고 싶은 질문을 3개 이상 정의한다.
질문은 “그래프로 확인 가능한 것”과 “추가 해석이 필요한 것”이 섞여도 된다.
데이터 정제 및 시계열 분석
데이터 기본 정보(기간, 컬럼, 결측치 여부)를 확인한다.
결측치/이상치가 있다면 기준을 정해 처리한다.
시계열 분석 기법을 최소 2가지 적용한다. (예: 이동평균, 변화율, 구간별 통계, 변동성/표준편차, 월별/요일별 집계 등)
시각화
필수: 시각화 2개 이상을 리포트에 포함한다.
권장: 추가 1개 이상(총 3개 이상)으로 분석 설득력을 높인다.
인사이트 도출 및 리포트 작성
인사이트를 3개 이상 도출한다.
각 인사이트는 “그래프에서 확인한 관찰(수치/근거)”을 포함해야 한다.
REPORT.md에 분석 주제, 질문, 데이터 설명, 시각화, 인사이트, 결론/한계점을 정리한다.

## 5. 보너스 과제

### 분석 결과 서비스화 (대시보드/웹)

제출은 아래 중 택1로 한다.

(2) 로컬 실행 화면 녹화(또는 시연 영상) + 실행 방법 문서
(3) 대시보드 스크린샷 세트 + 필터/기간 변경 시나리오 설명

아래 중 1개 이상을 추가로 수행하고, 결과를 시각화 1개 이상으로 남긴다.
(A) 시계열 분해: 추세/계절성을 분리해 해석 시도
(B) 간단 예측: 베이스라인 방식으로 짧은 구간 예측(정확도보다 “가정/한계” 설명에 집중)

# 삼성전자 2023~2024년 주가 트렌드 분석 리포트

## 1. 분석 주제 및 선정 이유

- 2023~2024년은 반도체 업황/금리/AI 기대감 등 외부 요인이 함께 거론된 시기
- 주가 흐름에서 “추세 변화가 있었는지”를 데이터로 확인해보고자 함

## 2. 분석 질문 (3개 이상)

## 1. 2023~2024년 전체적으로 상승/하락 추세가 있었는가?

## 2. 급등/급락 구간은 언제이며, 외부 이벤트(금리 발표, 실적, 산업 이슈 등)와 연결해볼 수 있는가?

## 3. 월별 수익률 패턴이 다른가? 특정 월이 유리/불리한 경향이 있는가?

## 3. 데이터 설명

- 출처: Yahoo Finance
- 기간: 2023-01-01 ~ 2024-12-31
- 데이터 수: N일(거래일 기준)

## 4. 분석 결과 및 시각화

- (필수 2개 + 권장 1개 이상) 그래프 삽입 및 간단 설명

## 5. 인사이트(3개 이상)

- 인사이트 예시 형식:
    - 관찰(Fact): 그래프에서 확인한 수치/구간
    - 원인(Why): 가능한 원인 가설 1~2개(근거/반례 포함 가능)
    - 행동(Action): 의사결정/추가 분석/다음 실험 제안

## 6. 결론 및 한계점

- 결론: (요약)
- 한계점: (외부 변수 미반영, 단일 지표 한계 등)

### 시각화 선택 간단 가이드

축: 시간 축이 올바른지(날짜 정렬/누락 구간) 확인한다.
스케일: 값 범위가 큰 경우, 스케일 때문에 변화가 “평평하게” 보이지 않는지 점검한다.
집계 단위: 일/주/월 단위를 바꾸면 패턴이 달라질 수 있으므로, 왜 그 단위를 선택했는지 리포트에 한 줄로라도 근거를 남긴다.
