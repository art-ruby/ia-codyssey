# 일본 YouTube 롱폼 콘텐츠 트렌드 분석

일본 YouTube 롱폼 영상 **632건** (2026-07-03 ~ 09-01, 60일치)을 수집·분석해,  
**구독자가 적은 채널에서 비정상적으로 잘 된 영상**이 어떤 조건에서 나오는지 살펴본 리포트.

조회수 상위 영상을 찾는 것이 목적이 아니다. 그 자리는 이미 큰 채널이 차지하고 있다.  
구독자 대비 조회수가 비정상적으로 높은 영상이 «아직 충분히 다뤄지지 않은 주제»를 가리킨다고 보고, 그것을 데이터로 찾는다.

## 분석 질문

1. 최근 일본 롱폼 영상의 조회 성과는 상승하고 있는가?
2. 구독자가 적은 채널 중 평소보다 비정상적으로 높은 조회수를 낸 영상이 있는가?
3. 한 영상의 우연한 성공과 채널 전체의 성장을 어떻게 구분하는가?
4. 어떤 주제가 상대적으로 좋은 성과를 내고, 공급은 어떻게 변하고 있는가?

## 핵심 발견

### 1. 겉보기 상승의 대부분은 지표의 편향이다
최근 4주 평균 조회 속도가 이전 4주 대비 +442%로 보인다. 실제 관심이 늘어난 것이 아니다.  
조회수를 경과일로 나누는 지표는 어린 영상일수록 구조적으로 높다 — «최근 vs 이전» 비교는 사실상 어린 영상과 늙은 영상을 비교하는 것이다. `人生` 검색어가 이 방식으론 16,000% 성장, 나이를 맞추면 꼴찌로 뒤집혔다.

### 2. 구독자 1만 이하에서 16%가 Outlier다
구독자 1,000명 이상 290건 중 47건(16%)이 구독자 대비 조회수 5배 이상.  
상위권: 구독 4,190명 → 502,006회(120배), 주제는 「AI 마을 방치 실험」(ゆっくり解説 형식).  
구독자가 아니라 검색·추천으로 유입됐다는 뜻 — 채널 규모와 무관하게 수요가 있다는 신호.

### 3. 좁은 검색어는 «맞는 주제»는 찾지만 «수요»는 못 보여준다
넓은 낱말(`老後·お金·AI`)은 조회수 중앙 67,550회, 롱테일(`定年後 住民税`)은 375회.  
예외 하나: `熟年離婚`(황혼이혼)은 좁은 검색어인데 중앙 2,971회/일, 공급도 9→52건 5.8배.  
넓은 낱말은 «수요 존재 여부»를, 롱테일은 «진입 여지»를 본다 — 어느 한쪽만으로는 판단 불가.

### 4. 영상만 터진 채널과 채널째 오르는 채널은 다르다
`ねっと`: 평소 수백 회 → 최근 5편 중앙 72,670회. 채널 전체가 올라선 사례.  
`都のオワリです`: 구독자 대비로는 눈에 띄나 그 채널 평소보다 오히려 못했다(기준 0.82배).  
Video Score와 Channel Score를 합산하지 않고 따로 낸 이유 — 합치면 이 차이가 사라진다.

```bash
pip install -r requirements.txt
python analysis.py
```

`images/` 에 그래프 3개를 다시 그리고, 인사이트 수치를 콘솔에 출력한다.

### 데이터 수집 (선택)

```bash
cp .env.example .env          # YOUTUBE_API_KEY 입력
```

## 시계열 분석 기법

| 기법 | 적용 내용 |
|---|---|
| **이동평균** | 게시 주차별 평균 조회 속도에 4주 이동평균 — 주간 노이즈 제거 |
| **변화율** | 최근 4주 평균 vs 이전 4주 평균 — «나이 편향» 검출에 사용 |
| **구간별 통계 (Age Bucket)** | 게시 후 경과일로 0~3·4~7·8~14·15~30·31~90일 구간 분리 — 나이가 같은 영상끼리 비교 |

나이 편향 없는 비교는 구간별 통계가 핵심이다. 같은 기간 비교가 아니라 «같은 나이대 안에서 어떤 영상이 잘했는가»를 본다.

## 이상치 처리 방침

일반 분석에서 이상치는 제거 대상이지만 여기서는 **찾는 대상**이다.

다만 두 가지는 잘라낸다.

**① 구독자 1,000명 미만** — 구독 6명 → 조회 1,461회 = 244배처럼, 분모가 작아서 비율이 튀는 것은 수요 신호가 아니다. 행을 지우지 않고 비율만 결측 처리 (632건 중 139건).

**② 참여율 1.5/1,000 미만** — 조회수 1,000회당 좋아요 1.5개 미만은 매크(구매 조회수) 방어선. 유사 도구 벤치마크에서 가져와 우리 데이터 분포로 재검증 후 동일 임계값 적용. 마찬가지로 비율만 결측, 행은 남긴다.

자른 결과: 구독자 1,000명 이상 대상에서 «참여율 바닥 & 구독대비 5배 이상»이 현재 0건 — 오염 징후는 없지만 예방선을 먼저 깔았다.

## 데이터 출처 및 재현

| 항목 | 내용 |
|---|---|
| 출처 | YouTube Data API v3 (공개 메타데이터만) |
| 수집일 | 2026-09-02 — API를 실제로 호출한 날 |
| 게시 기간 | 2026-07-03 ~ 2026-09-01 — 수집된 영상들의 YouTube 업로드 날짜 범위 |
| 수집 영상 | 777건 → 필터 후 분석 대상 **632건** |
| 채널 수 | 449개 |

**수집일 vs 게시 기간**: 수집은 2026-09-02 하루에 한 번 했다. 그날 검색어로 찾은 영상들이 YouTube에 올라온 날짜가 2026-07-03 ~ 2026-09-01 범위에 분포한다 — 최근 60일치 게시물을 검색 조건으로 걸었기 때문이다(`SEARCH_DAYS = 60`). 수집 기간(며칠 동안 모았는가)이 아니라 **데이터의 시간 범위**를 뜻한다.

### API 할당량

YouTube Data API v3는 Google이 무료로 제공하는 공개 API다. Google Cloud Console에서 프로젝트를 만들고 API를 활성화하면 기본 할당량이 주어진다.

**할당량 구조 (2026-06-01 개편 이후)**

Google이 2026년 6월부터 `search.list`를 별도 버킷으로 분리했다. 버킷이 둘이다.

| 버킷 | 한도 | 대상 메서드 | 이 프로젝트 소비 |
|---|---|---|---|
| **search 버킷** | 100회/일 | `search.list`만 | 16회/일 (16%) |
| **일반 버킷** | 10,000 units/일 | `videos.list`·`channels.list`·댓글 등 나머지 전부 | ~1,630 units/일 (16%) |

개편 전에는 `search.list` 1회가 100 units로 일반 버킷에서 빠졌다. 지금은 자기 버킷 1 unit을 쓰고, 일반 버킷과는 독립이다. 수치는 우연히 같지만(하루 100회) 소비 구조가 다르다.

두 한도 모두 **태평양 자정(PT 00:00, 한국 시간 오후 5시 또는 오전 5시 DST)**에 초기화된다. 한국 날짜로 세면 어긋나 하루가 남았다고 생각할 때 이미 초기화된 뒤일 수 있다.

**왜 16%만 쓰는가**

할당량을 초과하면 그날 추가 API 호출이 전부 막힌다. 수집은 매일 1회인데, 초과하면 **그날 조회수 스냅샷도 못 남긴다** — 지나간 날의 조회수는 다시 받을 수 없으므로 시계열에 구멍이 난다. 구멍이 생긴 날의 조회 증감을 영영 모르게 된다.

그래서 `collector.py`에 같은 날 두 번째 실행을 막는 가드를 넣었다(`--force`로 우회 가능). 정상 운영(수집 1회 + 스냅샷 1회 + 가끔 채널 검증)에서 16%가 유지되도록 검색어 수와 페이지 수를 맞췄고, 개발 중 테스트나 재실행에 대한 여유분을 남겨둔 수준이다.

수집 스크립트를 실행하면 동일 데이터를 재현할 수 있다. 원본 CSV는 용량·라이선스 이유로 미포함.  
재현 절차와 데이터 구조는 [data/README.md](data/README.md) 참고.

## 결론 및 한계점

### 결론 요약

- **나이 편향 제거**로 «최근 성과 상승(+442%)»의 실체가 지표 편향임을 밝혔다 — 실제 관심 변화가 아님
- **구독자 1,000명 이상 영상의 16%(47건)가 Outlier** — 채널 규모보다 콘텐츠 주제가 성과를 좌우함을 시사
- **Video Score와 Channel Score 분리**로 «영상 하나가 터진 것»과 «채널 전체가 성장하는 것»을 구분 가능
- **`熟年離婚`(황혼이혼)**: 좁은 검색어임에도 중앙 2,971회/일, 공급 5.8배 증가 — 수요와 공급이 동시에 움직이는 드문 주제

### 한계점

| 한계 | 내용 |
|---|---|
| 스냅샷 1회 | 수집일(2026-09-02) 기준 단일 스냅샷 — 시간에 따른 조회수 변화 추적이 제한적 |
| 언어 판정 휴리스틱 | 가나 비율 기반 일본어 판정 — 영어 제목+일본어 본문 영상은 오분류 가능 |
| 검색어 선정 편향 | 정해진 20개 키워드 외 주제는 미수집 |
| 콘텐츠 내용 미분석 | 썸네일·제목 문구·태그 미분석 — 주제 분류는 검색어 기반에 한정 |
