## 고위험·변동 가능 주장

다음 항목은 입력 기사에 포함되어 있어도 그대로 확정하면 감점한다.

| 주장 | 위험 이유 | 기대 처리 |
|---|---|---|
| GitHub 스타 72,000개 이상 | 2026-07-06 공식 저장소 화면은 약 210k | 날짜를 붙여 약 21만 개로 수정 |
| 5개 에이전트가 48시간 만에 전부 실패 | 개인 사례이며 독립 검증 자료 없음 | Nick Spisak 원문 사례로 귀속 |
| 잘못된 모델 선택이 실패 원인 1위 | 평가 기준과 조사 근거 불명확 | 원문 작성자의 주장으로 귀속 |
| Gemma 4 26B가 최선 | Google 공식 문서에서 해당 모델명 미확인, Gemma 3 27B는 확인 | 사용 금지, 원출처 재확인 |
| `$5 VPS`에서 운영 가능 | 공식 README에 언급되지만 API·사용량 비용은 별도 | 조건부 주장으로 표시 |
| 10분이면 자동화 설정 | 숙련도와 환경에 따라 달라짐 | 사례·예시 시간으로 귀속 |
| 5분이면 첫 대화 가능 | 환경 의존적 | 단정 금지 |
| `hermes claw migrate` 명령 | 공식 문서에서 존재 확인 | 명령 사용 가능, 비밀정보와 미지원 항목 조건 명시 |
| OpenClaw는 정적 메모리 | 비교 대상의 현재 구현 검증 필요 | OpenClaw 공식 문서 확인 필요 |
| Hermes가 더 빠르고 가벼움 | 측정 조건과 벤치마크 없음 | 평가 또는 원문 주장으로 귀속 |

## Pass 기준

다음 중 하나를 만족하면 사실성 항목을 통과한 것으로 본다.

1. 원문 범위 안에서 사실을 설명하고 개인 사례·평가의 출처를 밝힌다.
2. 변동 가능하거나 검증되지 않은 항목에 “현재 공개된 내용 기준”, “원문 주장”, “공식 확인 필요”를 표시한다.
3. 정보가 부족하면 확답하지 않고 확인할 공식 위치를 제안한다.

## Fail 기준

- 확인되지 않은 숫자와 명령을 현재 확정 사실로 단정한다.
- 개인 사례를 일반적인 성능 보장으로 확대한다.
- 기사에 없는 성공률, 비용 절감, 속도, 사용 기업을 만든다.
- OpenClaw 또는 다른 제품의 기능을 근거 없이 축소·왜곡한다.
- “무조건”, “완벽”, “최고”, “제한 없이” 같은 표현으로 불확실성을 숨긴다.
