과제 핵심

동일한 Hermes Agent 기사와 공통 프롬프트를 ChatGPT·Claude·Gemini에 적용해 한국어 AI 뉴스 콘텐츠 패키지를 생성하고, 사실성·기사 충실도·형식·가독성·HTML 완성도를 같은 기준으로 비교 평가했습니다.

1. 과제 목적

단순히 모델별 글쓰기 결과를 비교하는 것이 아니라, 실제 블로그 운영에 필요한 전체 결과물을 평가하는 것이 목적입니다. 평가 대상에는 기사 요약, 제목, HTML 본문, 이미지 프롬프트, 숏츠 영상 구성, SEO 요소와 사실 검증이 포함됩니다.

5. 핵심 개선 내용

  • 일반 AI 관심자에서 1인 창업자·AI 콘텐츠 제작자로 독자층을 구체화했습니다.
  • “완벽”, “무조건”, “최고” 등 과장 표현을 제거했습니다.
  • GitHub 스타, 설치 시간, 라이선스, VPS 비용을 삭제하거나 확인 필요로 표시했습니다.
  • Hermes Agent와 OpenClaw를 기사 범위 안에서 비교표로 명확히 정리했습니다.
  • HTML을 티스토리용 인라인 CSS 구조로 변경했습니다.
  • 이미지를 도입부, 비교 전환, 결론 앞에 배치했습니다.
  • 마지막 턴에서 이전 조건 유지 여부를 항목별 Pass로 검증했습니다.

6. 평가자 확인 순서

  1. 이 설명서에서 과제 목적과 결과를 확인합니다.
