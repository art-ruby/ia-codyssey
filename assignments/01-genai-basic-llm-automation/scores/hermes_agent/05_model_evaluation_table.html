4. 모델별 핵심 평가

ChatGPT — 86.5점

강점: 원문 범위를 반복적으로 표시하고 검증되지 않은 수치를 대부분 제외했다. 소제목 구조가 가장 풍부하고 인라인 CSS라 게시 전 수정량이 적다.

감점: 사실 확인 섹션과 SEO meta description이 없고, HTML title에 “차이 and 실전 활용법” 오타가 남았다.

Claude Sonnet 5 — 84.0점

강점: 사실 확인 항목, SEO meta, 인라인 HTML, Sora 필수 문구를 모두 반영했다. 이전 v5보다 사실성과 형식 준수가 크게 개선됐다.

감점: “전멸”, “성공 사례”처럼 표현이 강한 부분과 출처 귀속을 더 명확히 할 구간이 있다.

Gemini 3.1 Pro — 75.5점

강점: 사실 확인 필요 항목과 SEO meta description을 포함했다. 결론·출처·해시태그 구조가 완결적이다.

감점: 과장 표현과 입력 밖 추론이 있고, HTML이 인라인 CSS 계약을 지키지 않았다.
