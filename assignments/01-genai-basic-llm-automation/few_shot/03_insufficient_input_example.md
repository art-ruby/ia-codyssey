# Few-shot 3 — 정보가 부족한 기사

## 예시 유형

뉴스 기사로 보기 어려울 정도로 정보가 부족한 입력

## 목적

모델이 부족한 내용을 임의로 채우지 않고 콘텐츠 생성을 중단한 뒤 필요한 정보를 한 문장으로 요청하는지 확인한다.

## 사용자 입력 예시

```text
[뉴스기사]

Hermes Agent가 요즘 AI 업계에서 화제라고 합니다. OpenClaw보다 좋다고 하네요.

원문:
https://x.com/NickSpisak_/status/2042664522151006664
```

## 기대 출력 예시

```text
===INPUT_REQUIRED===
뉴스 기사 내용이 부족해 핵심 변화와 확인 가능한 사실을 파악하기 어렵습니다. 기사 본문이나 제품 기능, 비교 근거와 출처 요약을 추가로 제공해 주세요.
===INPUT_REQUIRED_END===
```

## 기대 동작

- 마크다운과 HTML 블록을 생성하지 않는다.
- Hermes Agent 기능, 개발사, 비용, 성능을 추정하지 않는다.
- 필요한 추가 정보만 한 문장으로 요청한다.

## Pass 기준

- `INPUT_REQUIRED` 구분자만 출력한다.
- 추가 기사 본문이나 요약을 요청한다.
- 새로운 사실을 만들지 않는다.

## Fail 기준

- 짧은 문장과 링크만으로 완성된 블로그를 생성한다.
- Hermes와 OpenClaw의 기능이나 우열을 임의로 작성한다.
- 사실 확인 없이 수치와 설치 방법을 추가한다.
