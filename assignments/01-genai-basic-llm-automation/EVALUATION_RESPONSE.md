# Assignment 01 평가 기준 대응 정리

## 0. 제출 범위

과제명: AI Tech News Blog Automation

업무 목표: AI 뉴스 기사 하나를 입력하면 3종 LLM이 블로그 게시용 콘텐츠 패키지를 생성하고, 사람이 모델별 결과를 비교해 최종 게시 모델을 선정한다.

사용 모델:

- ChatGPT 5.5
- Claude Sonnet 5
- Gemini 3.1 Pro

최종 선정 모델: ChatGPT 5.5

## 1. 업무 과업 정의

타겟 사용자는 1인 창업자, AI 콘텐츠 제작자, 기술 블로그 운영자다. 이 사용자는 최신 AI 도구 뉴스를 빠르게 블로그 콘텐츠로 바꾸되, 과장 표현과 환각을 줄이고 게시 가능한 HTML까지 얻고 싶어 한다.

입력 규격:

- 기사 제목
- 기사 본문
- 원문 URL
- 출처명
- 작성일 또는 확인일
- 타겟 독자
- 콘텐츠 목적
- 확인된 사실
- 확인이 필요한 주장

출력 규격:

- 핵심 주제
- 제목 후보 3개와 최종 제목
- 썸네일 문구 3개
- 한 줄 요약
- SEO 메타 설명
- Sora 2 영상 프롬프트, 내레이션, 자막
- 대표 이미지 프롬프트 3개와 alt 텍스트
- 해시태그 10개 이상
- 마크다운 콘텐츠 패키지
- 게시 가능한 HTML
- 사실 확인 필요 항목

```text

- GPTERS 분석 글
- Nick Spisak X 아티클
```


## 7. 프롬프트 분리

시스템 프롬프트 역할:

```text
너는 AI 뉴스 콘텐츠 패키지 생성기다. 기사에 없는 사실을 만들지 말고, 확인된 사실과 기사 주장과 해석을 분리한다. 정보가 부족하면 INPUT_REQUIRED로 되묻는다.
```

유저 프롬프트 역할:

```text
아래 기사와 작성 조건을 기준으로 블로그 콘텐츠 패키지를 생성하라. 출력은 MARKDOWN_START/MARKDOWN_END와 HTML_START/HTML_END로 분리하라.
```

입력 템플릿 역할:

```text
[기사 정보], [작성 조건], [사실 검증], [출력 요청] 블록으로 기사와 조건을 구조화한다.
```

| 항목 | v1 | v2 | 개선 |

| 스타 수 처리 | 72,000개를 현재 사실처럼 사용 | 최신 확인 필요로 분리 | 개선 |

v2를 최종 채택한 이유는 변동 가능 사실을 별도 확인 항목으로 분리하고, 모델별 결과를 같은 구조로 비교할 수 있기 때문이다.

## 9. 모델 비교의 구조화

모델 비교는 8개 축으로 구조화했다. 핵심 축은 사실 정확성, 입력 충실도, 형식 준수, 콘텐츠 구조, 한국어 가독성, HTML 완성도, 이미지/영상 연계, 운영 편의성이다.

## 10. 환각의 정의 및 구분

이 과제에서 환각은 입력 기사와 공식 출처로 확인되지 않은 사실을 확정적으로 생성하는 것이다. 예를 들어 존재가 확인되지 않은 모델명, 변동 수치, 비용 보장, API 키 자동 이전 같은 주장을 사실처럼 쓰면 환각으로 본다.

창의적 생성과 환각은 구분했다. 제목 후보, 썸네일 문구, 이미지 프롬프트, 문체 조정은 창의적 생성으로 허용했다. 단, 제품 기능, 라이선스, 명령어, 비용, 성능 비교는 출처 기반 사실 영역이므로 임의 생성하지 않도록 했다.

## 11. 환각 검증 판정 기준

| 판정 | 기준 |
|---|---|
| Pass | 공식 출처 또는 입력 기사와 일치하고 조건을 정확히 설명함 |
| Pass-safe | 위험한 주장을 반복하지 않거나 확인 필요로 분리함 |
| Fail | 공식 확인이 불가능하거나 틀린 내용을 확정 사실처럼 생성함 |
| 확인 필요 | 현재 자료만으로 확정할 수 없어 게시 전 추가 검증이 필요함 |

## 12. 모델 선정 이유

ChatGPT 5.5를 최종 선정했다. 이유는 총점 86.5점으로 가장 높고, 과제 특성상 중요한 사실성, 구조 안정성, HTML 이식성, 누적 조건 유지가 가장 균형적이었기 때문이다. 특히 11턴 대화에서 독자층, 제목, 수치 처리, HTML 형식, 이미지 위치 조건을 유지한 점이 실제 블로그 자동화 업무에 적합했다.

## 13. 심층 인터뷰 - 비용 제약

이 항목은 이번 1번 과제 제출 범위가 아니다. 현재 제출물은 LLM 기반 업무 자동화 산출물, 모델 비교, 프롬프트 개선, 환각 검증, 10턴 이상 대화 로그를 다룬다. 심층 인터뷰 답변은 별도 인터뷰 과제 또는 별도 제출 지시가 있을 때 작성할 항목이므로 본 과제 제출 자료에서는 제외한다.

참고용 사전평가 파일에 적었던 비용 제약 답변은 제출 대상에서 제외했다.

## 14. 심층 인터뷰 - 정책 변경

이 항목은 이번 1번 과제 제출 범위가 아니다. 정책 변경 대응 전략은 심층 인터뷰 문항에 해당하며, 현재 제출 요구 산출물인 입력 템플릿, 모델 비교표, Few-shot, 환각 검증, 대화 로그, 프롬프트 개선 과정과는 별도 성격의 답변이다.

따라서 제출 본문에서는 이 항목을 평가 대상에서 제외한다.

## 15. 심층 인터뷰 - 문맥 끊김

이 항목은 이번 1번 과제 제출 범위가 아니다. 문맥 끊김에 대한 인터뷰식 일반 답변은 별도 심층 인터뷰 자료이며, 현재 과제에서는 실제 11턴 대화 로그와 조건 유지 검증으로 대화형 수정 과정을 증빙했다.

심층 인터뷰 답변은 제출 대상에서 제외하고, 본 과제의 증빙은 `reports/03_conversation_execution_log.md`와 11턴 대화 로그로 한정한다.
