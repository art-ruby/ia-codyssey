# 벤치마크 자료 구조

이 디렉터리는 블로그 제작 기준을 목적별로 분리해 관리한다.

## 구분

| 구분 | 경로 | 용도 |
|---|---|---|
| 형식 벤치마크 | `format/` | 글꼴, 여백, 강조, 박스, 이미지 배치, 해시태그 등 표현 방식 |
| 인용 사이트 벤치마크 | `sources/` | 참고 URL, 확인 범위, 관찰 근거, 사용 시 주의점 |
| 콘텐츠 벤치마크 | `content/` | 주제 전개, 정보 밀도, 분석 방식 등 추후 제공할 콘텐츠 기준 |

형식 벤치마크는 디자인과 문서 구조만 참고한다. 원문의 문장이나 고유 콘텐츠를 복제하지 않는다.

## 현재 등록 자료

- 형식: `format/naver_ninestonelee/`
- 인용 사이트: `sources/naver_ninestonelee.md`
- 콘텐츠: `content/hermes_agent_gpters/`
- 콘텐츠 인용 사이트: `sources/hermes_agent_gpters.md`
