## 🎯 보너스 1: 프롬프트 영속화 및 내보내기

### 문제점
- **기존**: 프로그램 종료 시 추가한 프롬프트가 모두 사라짐
- **이유**: 메모리에만 저장하고 파일로 보관하지 않음

### 해결 방법
#### 1️⃣ JSON 파일로 저장 (데이터 영속화)

**구현 코드:**
```python
import json
import os

def load_prompts():
    """JSON 파일에서 프롬프트를 불러오는 함수"""
    global prompts
    if os.path.exists("prompts.json"):
        with open("prompts.json", "r", encoding="utf-8") as f:
            prompts = json.load(f)

def save_prompts():
    """프롬프트를 JSON 파일로 저장하는 함수"""
    with open("prompts.json", "w", encoding="utf-8") as f:
        json.dump(prompts, f, ensure_ascii=False, indent=2)
```

**동작:**
- 프로그램 시작 시: `load_prompts()` 자동 호출 → `prompts.json` 불러오기
- 프롬프트 추가/수정/삭제 시: `save_prompts()` 자동 호출 → 파일에 저장
- 프로그램 종료 후에도 데이터 유지 ✅

**파일 형식:**
```json
[
  {
    "title": "블로그 글 작성 도우미",
    "content": "당신은 10년 경력의...",
    "category": "텍스트 생성",
    "favorite": false,
    "view_count": 5
  },
  {
    "title": "제품 썸네일 생성",
    "content": "다음 제품의 매력적인...",
    "category": "이미지 생성",
    "favorite": true,
    "view_count": 3
  }
]
```

#### 2️⃣ Markdown으로 내보내기

**구현 코드:**

```python
def export_to_markdown():
    """전체 프롬프트를 카테고리별 Markdown 파일로 내보내는 함수"""
    category_prompts = {}
    
    # 카테고리별 그룹화
    for prompt in prompts:
        cat = prompt["category"]
        if cat not in category_prompts:
            category_prompts[cat] = []
        category_prompts[cat].append(prompt)

    for category in CATEGORIES:
        if category in category_prompts:
            filename = f"prompts_{category}.md"
            with open(filename, "w", encoding="utf-8") as f:
                f.write(f"# {category} 카테고리 프롬프트\n\n")
                for prompt in category_prompts[category]:
                    f.write(f"## {prompt['title']}\n\n")
                    f.write(f"**조회수**: {prompt.get('view_count', 0)}\n\n")
                    f.write(f"{prompt['content']}\n\n")
```

**생성되는 파일:**

- `prompts_페르소나.md`
- `prompts_자동화.md`
- `prompts_기타.md`

**사용 경우:**
- 프롬프트를 문서 형태로 공유하고 싶을 때

```python
def update_prompt():
    """프롬프트를 수정하는 함수"""
    num = int(input("수정할 프롬프트 번호 입력: "))
    
    if 1 <= num <= len(prompts):
        prompt = prompts[num - 1]
        
        # 제목 수정
        new_title = input("새 제목: ").strip()
        if new_title:
            prompt["title"] = new_title
        
        # 내용 수정
        new_content = input("새 내용: ").strip()
        if new_content:
            prompt["content"] = new_content
        
        # 카테고리 수정
        choice = input("새 카테고리 번호: ").strip()
        if choice:
            prompt["category"] = CATEGORIES[int(choice) - 1]
        
        save_prompts()  # 수정 후 저장
```

**장점:**
- 각 필드를 선택적으로 수정 가능
- 불필요한 필드는 엔터로 스킵
- 수정 후 자동으로 JSON 파일 업데이트

```python
def delete_prompt():
    """프롬프트를 삭제하는 함수"""
    num = int(input("삭제할 프롬프트 번호 입력: "))
    
    if 1 <= num <= len(prompts):
        prompt = prompts[num - 1]
        title = prompt["title"]
        
        # 확인 메시지
        confirm = input(f"'{title}'을 정말 삭제하시겠습니까? (y/n): ")
        
        if confirm.lower() == "y":
            prompts.pop(num - 1)  # 리스트에서 제거
            save_prompts()         # 파일에 저장
            print(f"✅ '{title}'이 삭제되었습니다!")
```

**특징:**
- 삭제 전 확인 메시지로 실수 방지
- 삭제 후 자동 저장

### 기능 2-4: Top 목록 (인기 프롬프트)

**메뉴 10 - 인기 프롬프트**

```python
def show_top_prompts():
    """조회수가 높은 프롬프트 Top 목록"""
    
    # 조회수로 정렬 (내림차순)
    sorted_prompts = sorted(
        enumerate(prompts, 1), 
        key=lambda x: x[1].get("view_count", 0), 
        reverse=True
    )
    
    print("\n조회수 기준 정렬:\n")
    for rank, (num, prompt) in enumerate(sorted_prompts, 1):
        print(f"{rank}. {prompt['title']}")
        print(f"   카테고리: {prompt['category']} | 조회수: {prompt.get('view_count', 0)}")
```

**사용 사례:**
- 가장 자주 사용되는 프롬프트 파악
- 반복적으로 쓰는 프롬프트 발견
- 효율성 분석

**예시 출력:**
```
인기 프롬프트 (조회수 기준):

1. 블로그 글 작성 도우미 ⭐
   카테고리: 텍스트 생성 | 조회수: 15

2. IT 컨설턴트 페르소나
   카테고리: 페르소나 | 조회수: 8

3. 제품 썸네일 생성
   카테고리: 이미지 생성 | 조회수: 3
```
