# 🎯 프롬프트 관리 프로그램

AI 프롬프트를 체계적으로 관리하고 활용하기 위한 Python 콘솔 애플리케이션입니다.

---

## 📋 프로젝트 개요

GenAI 미션에서 작성한 프롬프트들이 여러 곳에 흩어져 있는 문제를 해결하기 위해, Python 콘솔 프로그램으로 프롬프트를 한곳에서 관리할 수 있도록 개발한 프로젝트입니다.

---

## 💻 개발 환경

- **Python**: 3.11.9
- **Git**: 2.55.0.windows.1
- **OS**: Windows 11 Pro
- **IDE**: Visual Studio Code

## ✨ 주요 기능

### 기본 기능 (1-7번)

### 1️⃣ 프롬프트 추가
제목, 내용, 카테고리를 입력하여 새로운 프롬프트 등록

### 2️⃣ 프롬프트 목록
저장된 모든 프롬프트를 번호, 카테고리, 즐겨찾기, 조회수와 함께 표시

### 3️⃣ 카테고리별 조회
6가지 카테고리(텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타) 중 선택하여 필터링

### 4️⃣ 프롬프트 검색
제목과 내용에서 키워드로 검색 (대소문자 무시)

### 5️⃣ 프롬프트 상세 보기
선택한 프롬프트의 전체 내용 표시 (자동으로 조회수 증가)

### 6️⃣ 즐겨찾기 관리
프롬프트를 즐겨찾기에 추가/제거

### 7️⃣ 즐겨찾기 목록
즐겨찾기된 프롬프트만 모아서 표시

---

### 보너스 기능 (8-12번) 🎁

### 8️⃣ 프롬프트 수정
제목, 내용, 카테고리를 변경할 수 있습니다

### 9️⃣ 프롬프트 삭제
프롬프트를 삭제합니다 (확인 필수)

### 🔟 인기 프롬프트 (Top)
조회수 기준으로 정렬된 프롬프트 목록을 표시합니다

### 1️⃣1️⃣ Markdown으로 내보내기
카테고리별로 Markdown 파일(`.md`)로 내보내기

### 1️⃣2️⃣ 프롬프트 저장
프롬프트를 JSON 파일(`prompts.json`)로 수동 저장

## 📝 주의사항

- **프롬프트는 자동으로 저장됩니다** (`prompts.json` 파일)
- 프로그램 종료 시에도 이전 데이터가 유지됩니다
- Python 3.10 이상 필요
- UTF-8 인코딩 환경 권장

## 🎁 보너스 기능 상세

### 프롬프트 영속화
- 프로그램을 종료해도 `prompts.json` 파일에 모든 데이터 저장
- 다시 시작할 때 자동으로 이전 데이터 로드

### CRUD 관리
- **Create**: 프롬프트 추가 (메뉴 1)
- **Read**: 프롬프트 보기 (메뉴 2, 5, 7)
- **Update**: 프롬프트 수정 (메뉴 8)
- **Delete**: 프롬프트 삭제 (메뉴 9)

### 사용 기록 및 분석
- 상세 보기 시마다 조회수 자동 증가
- Top 목록으로 인기 프롬프트 확인
- 모든 목록에서 조회수 함께 표시

### 내보내기 기능
- 카테고리별로 Markdown 파일 생성
- 각 파일에 제목, 조회수, 즐겨찾기 상태, 내용 포함
