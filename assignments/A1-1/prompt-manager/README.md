# 🎯 프롬프트 관리 프로그램

AI 프롬프트를 체계적으로 관리하고 활용하기 위한 Python 콘솔 애플리케이션입니다.

---

## 📋 프로젝트 개요

GenAI 미션에서 작성한 프롬프트들이 여러 곳에 흩어져 있는 문제를 해결하기 위해, Python 콘솔 프로그램으로 프롬프트를 한곳에서 관리할 수 있도록 개발한 프로젝트입니다.

---

## 💻 개발 환경

- **Python**: 3.11.9
- **Git**: 2.55.0.windows.1
- **OS**: Windows 11 Pro
- **IDE**: Visual Studio Code

---

## 🚀 설치 및 실행

### 1. 저장소 복제
```bash
git clone https://github.com/art-ruby/ia-codyssey.git
cd ia-codyssey/assignments/A1-1/prompt-manager
```

### 2. 프로그램 실행
```bash
python prompt_manager.py
```

### 3. 메뉴 사용
```
========================================
    나만의 프롬프트 관리
========================================
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
========================================
선택: 
```

## ✨ 주요 기능

### 1️⃣ 프롬프트 추가
제목, 내용, 카테고리를 입력하여 새로운 프롬프트 등록

### 2️⃣ 프롬프트 목록
저장된 모든 프롬프트를 번호, 카테고리, 즐겨찾기 상태와 함께 표시

### 3️⃣ 카테고리별 조회
6가지 카테고리(텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타) 중 선택하여 필터링

### 4️⃣ 프롬프트 검색
제목과 내용에서 키워드로 검색 (대소문자 무시)

### 5️⃣ 프롬프트 상세 보기
선택한 프롬프트의 전체 내용 표시

### 6️⃣ 즐겨찾기 관리
프롬프트를 즐겨찾기에 추가/제거

### 7️⃣ 즐겨찾기 목록
즐겨찾기된 프롬프트만 모아서 표시
