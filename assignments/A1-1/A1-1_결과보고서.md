### 3-3. `.gitignore` 생성 단계 — 첫 번째 걸림돌

**문제 1**: VSCode 에디터에서 `.gitignore` 파일에 내용을 입력하고 `Ctrl+S`를 눌렀으나 파일 시스템에 저장되지 않는 현상 발생. `Get-ChildItem -Force`로 확인해도 `.git` 폴더만 보이고 `.gitignore`는 나타나지 않았다.

**원인 추정**: VSCode에서 새 파일을 만들 때 상위 폴더(`A1-1`)가 열려 있는 상태에서 저장이 씹히거나, 편집 포커스가 기대와 다른 파일에 가 있었던 것으로 추정.

**해결**: PowerShell 여기문서(here-string)를 이용해 터미널에서 직접 파일을 생성하는 방식으로 전환:

```powershell
@"
__pycache__/
*.pyc
*.pyo
.vscode/
.env
"@ | Out-File -Encoding utf8 .gitignore
```

**문제 2**: 위 방법으로 생성한 뒤에도 `git add .gitignore`가 `fatal: pathspec '.gitignore' did not match any files`를 반환. `Get-ChildItem -Force` 결과에는 파일이 있는데 Git은 인식하지 못하는 모순적 상황.

**진단**: `git status`를 실행해보니 실제로는 `.gitignore`가 **Untracked files**로 정상 인식되고 있었다. 즉 `git add` 실패는 일시적 타이밍/경로 문제였고, `git status` 확인 후 재시도한 `git add .gitignore`는 정상 동작했다(경고만 출력: `LF will be replaced by CRLF`, Windows 줄바꿈 관련 정상 경고).

```powershell
PS ...\prompt-manager> git add .gitignore
warning: in the working copy of '.gitignore', LF will be replaced by CRLF...
PS ...\prompt-manager> git commit -m "chore: .gitignore 파일 생성"
[main (root-commit) 8c43d96] chore: .gitignore 파일 생성
 1 file changed, 5 insertions(+)
 create mode 100644 .gitignore
```

**교훈**: VSCode 저장 상태를 100% 신뢰하지 말고, 의심스러우면 항상 `git status`로 실제 워킹 트리 상태를 먼저 확인한다.

### 3-5. 함수 구현 단계 — 반복된 IndentationError

기능을 하나씩 추가하는 과정에서 총 2회의 `IndentationError`가 발생했다.

**1차**: `main()` 함수의 `elif choice == "1":` 다음 줄에 `add_prompt()` 호출문을 들여쓰기 없이 붙여넣어 발생.
```
IndentationError: expected an indented block after 'elif' statement on line 72
```
→ 4칸 들여쓰기로 수정 후 정상화.

**2차**: `show_detail()` 함수를 새로 추가하면서 `def show_detail():` 바로 다음 줄(독스트링)에 들여쓰기가 빠져 발생.
```
IndentationError: expected an indented block after function definition on line 63
```
→ 동일하게 4칸 들여쓰기 적용 후 정상화.

두 사례 모두 "함수 정의부/제어문 다음 줄은 반드시 4칸 들여쓰기"라는 Python 문법 원칙을 다시 확인하는 계기가 되었다.

### 3-8. GitHub 원격 저장소 URL 오류 — 세 번째, 가장 큰 걸림돌

`git push origin main` 실행 시 다음 오류 발생:

```
remote: Not Found
fatal: repository 'https://github.com/art-ruby/a1-1/prompt-maniger.git/' not found
```

`git remote -v`로 확인하니 초기 설정 단계에서 입력한 원격 URL 자체가 다음과 같이 잘못되어 있었다:

```
https://github.com/art-ruby/a1-1/prompt-maniger.git
                        ↑ 존재하지 않는 경로   ↑ 오타(manager → maniger)
```

또한 애초에 이 프로젝트는 **독립적인 새 GitHub 저장소**가 아니라 기존 `ia-codyssey` 모노레포의 `assignments/A1-1/` 하위 폴더에 들어가야 하는 구조였다는 점도 이 시점에 재확인했다.

**해결 과정**:
1. `git remote -v`로 잘못된 URL 확인
2. `prompt-manager/` 안의 `.git` 폴더(독립 저장소 흔적)를 완전히 제거 — 처음에는 `rm -r`로 시도했으나 Windows 권한 문제로 다수의 `PermissionDenied` 오류 발생, `Remove-Item -Recurse -Force`로 재시도하여 해결
3. `__pycache__/` 캐시 폴더도 함께 제거
4. 메인 저장소 루트(`C:\ia-codyssey`)에서 `git status`로 상태 재확인 후, `prompt-manager` 폴더 전체를 **ia-codyssey 저장소의 일반 파일**로 편입
5. `git add assignments/A1-1/` → `git commit` → `git push origin main`으로 최종 반영

```powershell
PS C:\ia-codyssey> git add assignments/A1-1/
```

### 4-2. `prompt_manager.py` (238줄, 함수 8개)

```python
from data import CATEGORIES, prompts

def add_prompt():
    """새로운 프롬프트를 추가하는 함수"""
    print("\n" + "="*40)
    print("프롬프트 추가")
    print("="*40)

    # 제목 입력
    while True:
        title = input("제목: ").strip()
        if title:
            break
        print("제목을 입력해주세요.")

    # 내용 입력
    while True:
        content = input("내용: ").strip()
        if content:
            break
        print("내용을 입력해주세요.")

    # 카테고리 선택
    print("\n카테고리 선택:")
    for i, category in enumerate(CATEGORIES, 1):
        print(f"{i}) {category}")

    while True:
        try:
            choice = int(input("선택: "))
            if 1 <= choice <= len(CATEGORIES):
                category = CATEGORIES[choice - 1]
                break
            else:
                print("올바른 번호를 입력해주세요.")
        except ValueError:
            print("숫자를 입력해주세요.")

    # 프롬프트 추가
    new_prompt = {
        "title": title,
        "content": content,
        "category": category,
        "favorite": False
    }
    prompts.append(new_prompt)

    print(f"\n✅ '{title}' 프롬프트가 추가되었습니다!")


def show_list():
    """저장된 모든 프롬프트를 보는 함수"""
    print("\n" + "="*40)
    print("프롬프트 목록")
    print("="*40)

    if not prompts:
        print("저장된 프롬프트가 없습니다.")
        return

    for i, prompt in enumerate(prompts, 1):
        favorite_mark = "⭐" if prompt["favorite"] else " "
        print(f"{i}. [{prompt['category']}] {prompt['title']} {favorite_mark}")

    print(f"\n총 {len(prompts)}개의 프롬프트")


def show_detail():
    """선택한 프롬프트의 상세 정보를 보는 함수"""
    print("\n" + "="*40)
    print("프롬프트 상세 보기")
    print("="*40)

    if not prompts:
        print("저장된 프롬프트가 없습니다.")
        return

    try:
        num = int(input("번호 입력: "))
        if 1 <= num <= len(prompts):
            prompt = prompts[num - 1]
            favorite_mark = "⭐" if prompt["favorite"] else " "

            print("\n" + "-"*40)
            print(f"제목: {prompt['title']}")
            print(f"카테고리: {prompt['category']}")
            print(f"즐겨찾기: {favorite_mark}")
            print("-"*40)
            print(f"내용:\n{prompt['content']}")
            print("-"*40)
        else:
            print("존재하지 않는 번호입니다.")
    except ValueError:
        print("숫자를 입력해주세요.")


def search_prompt():
    """키워드로 프롬프트를 검색하는 함수"""
    print("\n" + "="*40)
    print("프롬프트 검색")
    print("="*40)

    if not prompts:
        print("저장된 프롬프트가 없습니다.")
        return

    keyword = input("검색어: ").strip()

    if not keyword:
        print("검색어를 입력해주세요.")
        return

    results = []
    for i, prompt in enumerate(prompts):
        if keyword.lower() in prompt["title"].lower() or keyword.lower() in prompt["content"].lower():
            results.append((i + 1, prompt))

    if results:
        print(f"\n검색 결과:")
        for num, prompt in results:
            favorite_mark = "⭐" if prompt["favorite"] else " "
            print(f"{num}. [{prompt['category']}] {prompt['title']} {favorite_mark}")
        print(f"\n{len(results)}개의 프롬프트를 찾았습니다.")
    else:
        print(f"\n'{keyword}'를 포함하는 프롬프트가 없습니다.")


def show_by_category():
    """카테고리별로 프롬프트를 조회하는 함수"""
    print("\n" + "="*40)
    print("카테고리별 조회")
    print("="*40)

    if not prompts:
        print("저장된 프롬프트가 없습니다.")
        return

    print("\n카테고리 선택:")
    for i, category in enumerate(CATEGORIES, 1):
        print(f"{i}) {category}")

    try:
        choice = int(input("\n선택: "))
        if 1 <= choice <= len(CATEGORIES):
            selected_category = CATEGORIES[choice - 1]

            print(f"\n[{selected_category}] 카테고리 프롬프트:")
            results = []
            for i, prompt in enumerate(prompts):
                if prompt["category"] == selected_category:
                    results.append((i + 1, prompt))

            if results:
                for num, prompt in results:
                    favorite_mark = "⭐" if prompt["favorite"] else " "
                    print(f"{num}. {prompt['title']} {favorite_mark}")
                print(f"\n총 {len(results)}개의 프롬프트")
            else:
                print(f"{selected_category} 카테고리에 프롬프트가 없습니다.")
        else:
            print("올바른 번호를 입력해주세요.")
    except ValueError:
        print("숫자를 입력해주세요.")


def toggle_favorite():
    """프롬프트의 즐겨찾기를 추가/해제하는 함수"""
    print("\n" + "="*40)
    print("즐겨찾기 관리")
    print("="*40)

    if not prompts:
        print("저장된 프롬프트가 없습니다.")
        return

    try:
        num = int(input("프롬프트 번호 입력: "))
        if 1 <= num <= len(prompts):
            prompt = prompts[num - 1]

            if prompt["favorite"]:
                prompt["favorite"] = False
                print(f"\n❌ '{prompt['title']}' 프롬프트를 즐겨찾기에서 제거했습니다!")
            else:
                prompt["favorite"] = True
                print(f"\n⭐ '{prompt['title']}' 프롬프트를 즐겨찾기에 추가했습니다!")
        else:
            print("존재하지 않는 번호입니다.")
    except ValueError:
        print("숫자를 입력해주세요.")


def show_favorites():
    """즐겨찾기된 프롬프트 목록을 보는 함수"""

    else:
        print("즐겨찾기된 프롬프트가 없습니다.")


def show_menu():
```

## 10. 결론 및 회고

### 잘된 점

- **작은 단위로 쪼개서 진행**한 것이 실수를 빠르게 잡는 데 유효했다. 기능 하나 → 실행 테스트 → 커밋을 반복하는 사이클 덕분에 `IndentationError`처럼 흔한 실수도 그 즉시 발견해 수정할 수 있었다.
- `git status`를 습관적으로 확인하는 것이 "화면에 보이는 것"과 "Git이 실제로 인식하는 상태"의 괴리를 해소하는 데 결정적이었다(3-3, 트러블슈팅 #2).

### 아쉬웠던 점 / 배운 점

- **원격 저장소 구조를 먼저 확정하지 않고 로컬 작업부터 시작**한 것이 가장 큰 시행착오의 원인이었다. `prompt-manager`를 독립 저장소로 `git init` 해버린 뒤에야 실제로는 `ia-codyssey` 모노레포의 하위 폴더여야 한다는 것을 깨달았고, 이 때문에 `.git` 폴더 강제 삭제, 원격 URL 재설정, 폴더 재편입이라는 우회 작업이 필요했다. **다음에는 "이 코드가 최종적으로 어느 저장소, 어느 경로에 들어갈지"를 작업 착수 전에 먼저 확정**할 것.
- Windows PowerShell 환경에서 `rm -r`, `ls -la` 같은 POSIX 스타일 명령이 그대로 통하지 않는 경우가 많아(`Remove-Item -Recurse -Force`, `Get-ChildItem -Force` 사용 필요) 셸 문법 차이로 인한 시간 소모가 있었다.

### 학습 성과

- Python: 리스트·딕셔너리 조합 데이터 모델링, `enumerate`, 문자열 검색(`in`, `lower()`), `try/except`를 통한 입력 검증, 함수 단위 관심사 분리
- Git: `init/add/commit/push/pull/checkout/merge`의 실전 사용, 브랜치 전략, 원격 저장소 URL 트러블슈팅, `git status`를 통한 상태 검증 습관
- 소프트웨어 개발 프로세스: 요구사항을 단계별 작업 목록으로 분해하고, 각 단계마다 실행 검증 후 커밋하는 점진적 개발 방식
