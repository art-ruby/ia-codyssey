# 블로그 형식 벤치마크 명세

## 1. 기준 자료

- 관찰 대상: 네이버 블로그 `ninestonelee`
- 참고 범위: 사용자가 제공한 스크린샷 3장과 공개 블로그 화면
- 벤치마크 유형: 형식
- 콘텐츠 벤치마크 여부: 아님

## 2. 전체 레이아웃

- 본문은 흰색 단일 컬럼으로 구성한다.
- 읽기 영역은 데스크톱 기준 약 `740~820px` 너비를 권장한다.
- 본문 좌우에 충분한 여백을 두고 장식 요소는 최소화한다.
- 문단, 박스, 이미지 사이에 명확한 수직 간격을 둔다.
- 모바일에서는 좌우 여백을 `18~24px` 수준으로 줄인다.

## 3. 제목과 본문 글자

### 제목

- 한 줄 또는 두 줄의 설명형 제목을 사용한다.
- 크기: 데스크톱 `38~46px`, 모바일 `30~36px`
- 굵기: `400~500`
- 줄간격: `1.35~1.5`
- 색상: 짙은 회갈색 또는 네이비 계열
- 자극적 표현보다 독자가 바로 이해할 수 있는 질문형·설명형 제목을 우선한다.

### 본문

- 크기: 데스크톱 `19~22px`, 모바일 `17~19px`
- 줄간격: `1.8~2.0`
- 문단은 `1~3문장` 중심으로 짧게 구성한다.
- 핵심 문장 앞뒤에는 한 줄 이상의 여백을 둔다.
- 문장 폭이 길어지지 않도록 읽기 영역을 제한한다.

## 4. 도입부 구성

권장 흐름:

1. 이모지 또는 짧은 시각적 훅
2. 독자가 공감할 질문
3. 기존 인식 또는 문제 상황
4. 이번 글에서 다룰 관점 제시

도입부는 핵심 주제로 빠르게 진입하며, 세부 설명은 뒤 문단으로 넘긴다.

## 5. 형광펜과 색상 강조

한 문단에서 강조 색상은 최대 두 종류만 사용한다.

| 역할 | 권장 색상 | 사용 방식 |
|---|---|---|
| 핵심 주제 | 코럴·주황 `#ff5a36` | 중요한 명사나 결론에 연한 배경 강조 |
| 비교·전환 | 파랑 `#2196f3` | 새로운 관점이나 비교 기준에 연한 배경 강조 |

권장 CSS 예시:

```html
<strong style="color:#ff5a36; background:#fff0e8; padding:1px 4px;">핵심어</strong>
<strong style="color:#168af2; background:#e8f4ff; padding:1px 4px;">전환어</strong>
```

강조는 문장 전체가 아니라 핵심 단어 또는 짧은 구에만 적용한다.

## 6. 정보 박스 유형

### 파란색 핵심·결론 박스

- 용도: 핵심 전략, 오늘의 결론, 요약
- 배경: `#e3f2fd` 계열
- 왼쪽 테두리: `4~6px solid #2196f3`
- 내부 여백: `16~22px`
- 제목 앞에 `💡` 등 의미가 분명한 이모지를 한 개 사용한다.

### 보라색 주의·관점 박스

- 용도: 투자·수익보다 먼저 볼 기준, 주의사항, 관점 전환
- 배경: `#f4e8f7` 계열
- 왼쪽 테두리: `4~6px solid #9c27b0`
- 경고문보다 판단 기준을 차분히 설명한다.

### 초록색 체크리스트 박스

- 용도: 단계, 목록, 얻을 수 있는 것, 실행 항목
- 배경: 매우 연한 초록 또는 흰색
- 테두리: `2px solid #2ea84a`
- 항목은 줄 단위로 분리하고 `1단계`, `2단계`처럼 순서를 명확히 한다.

### 회색 해시태그 박스

- 용도: 글 하단 추천 해시태그
- 배경: `#f7f8fa`
- 왼쪽 테두리: `4~6px solid #7b8794`
- 해시태그는 쉼표 또는 적절한 줄바꿈으로 구분한다.

## 7. 이미지 배치

- 이미지는 본문 흐름을 전환하는 지점에 배치한다.
- 권장 순서: 설명 문단 → 요약/목록 박스 → 이미지 → 다음 해설
- 이미지 너비는 본문 폭에 맞추고 과도한 테두리는 사용하지 않는다.
- 이미지 위아래에 `28~44px` 여백을 둔다.
- 장식 이미지보다 기사 내용과 직접 연결되는 설명형 이미지를 우선한다.
- 모든 이미지에 내용 중심의 한국어 `alt` 텍스트를 작성한다.

## 8. 글 마무리

권장 순서:

1. 파란색 결론 박스
2. 기준 시점과 출처
3. 회색 추천 해시태그 박스

결론은 새 주장을 추가하지 않고, 본문 핵심을 2~3문장으로 압축한다.

## 9. 적용 체크리스트

- [ ] 도입부 3~4문장 안에 핵심 변화가 제시되었는가
- [ ] 한 문단이 1~3문장으로 유지되는가
- [ ] 강조 색상이 문단당 두 종류 이하인가
- [ ] 박스마다 요약·주의·목록 등 역할이 명확한가
- [ ] 이미지가 내용 전환 지점에 배치되었는가
- [ ] 결론, 출처, 해시태그 순으로 끝나는가
- [ ] 원문 고유 문장이나 이미지를 복제하지 않았는가
