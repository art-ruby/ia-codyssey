# 네이버 블로그 형식 벤치마크

## 목적

네이버 블로그 `ninestonelee`의 글 표현 방식을 참고해 AI 뉴스 블로그의 가독성 기준을 정의한다. 이 자료는 콘텐츠 출처가 아니라 형식 참고 자료다.

## 파일

- `format_benchmark.md`: 블로그 제작에 적용할 형식 규칙
- `screenshots/01_title_intro_highlights.png`: 제목, 도입부, 색상 강조, 핵심 박스
- `screenshots/02_callout_checklist_image.png`: 주의 박스, 체크리스트 박스, 본문 이미지
- `screenshots/03_conclusion_hashtags.png`: 결론 박스, 출처 표기, 해시태그 영역

## 적용 범위

- 제목과 본문 계층
- 짧은 문단과 행간
- 핵심어 형광펜 강조
- 정보 성격별 박스 디자인
- 이미지 전후 여백
- 결론과 해시태그 마무리

## 제외 범위

- 원문 문장 복제
- 원문 주제와 주장 차용
- 작성자 고유 이미지 재사용
- 네이버 서비스 UI 복제
